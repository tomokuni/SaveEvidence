## 1. 対象利用者

- `App.WinUI3` を起動して画面キャプチャを行う**エンドユーザー**
- 同じコア（`App.Core`）を使う**別 UI の実装者**

## 2. 起動要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10（バージョン 19041）以降 |
| ランタイム | .NET 10（デスクトップ） |
| グラフィックス | WinUI 3（DirectX・Composition）と XAML の要素 |
| 配置 | アンパッケージ / Windows App SDK 自己完結（Windows App Runtime の導入は不要） |

`App.WinUI3` は **GUI アプリ（WinExe）** です。 コンソール出力は持ちません。

- **タイトル バーの帯は作りません**（ページ領域はクライアント領域の先頭から始まります）。 左上には、タスク バーと同じアプリ アイコンだけを置きます（**ナビゲーションのアイコンと同じ大きさ**で、**縦位置はツールバーのアイコンと揃え**、**横位置はナビゲーションの開閉アイコンと同じ列**に置きます）。 **左クリックでナビの開閉**、**右クリックでウィンドウ メニュー**（「元のサイズに戻す / 移動 / サイズ変更 / 最小化 / 最大化 / 閉じる」。 項目と並びは `WindowMenu`（App.Core）が単一所有する）を出します。
- **ナビゲーション パネル**はページ領域の上へ重なり（上端はページ領域の先頭、下端はステータス バーに被る）、一番上にアプリ アイコン、その下に開閉ボタン（アイコンのみ。 開いているとき `ic_fluent_panel_left_contract_24_filled.svg`、閉じているとき `ic_fluent_panel_right_contract_24_filled.svg`）を置きます。 **展開時は左上のアプリ アイコンの右にアプリ名（SaveEvidence）**を表示します（アイコンとの間隔は狭くします）。 展開しても**ページ領域は動きません**。
- 展開中に**ナビ領域の外**（ページ領域・タイトル バー相当の上端・ウィンドウの外）を操作すると収納へ戻ります。
- ウィンドウの最小外寸は枠を含めて 640 × 400 DIP、既定外寸は枠を含めて 1200 × 800 DIP です（`WindowMetrics`（App.Core）が単一所有する）。
- ツールバーのボタン高・アイコン寸法・文字サイズは `ToolbarMetrics`（App.Core）が共有し、アイコン単独のボタンは 32 × 32 DIP です。 キャプチャ メニューの保存・スクリーン / ウィンドウ / 範囲選択・切り出しには各ツールバーと同じ SVG アイコンを表示します。
- ナビゲーションのアイコン（項目・開閉・左上のアプリ アイコン）は**ツールバーのアイコンと同じ大きさ**（`NavPanelMetrics.IconSize` = 16 DIP。 App.Core が単一所有）です。

## 3. 画面仕様

左ペイン（**自前のアイコン列**。 展開時はページ領域の上へ重ねる一覧）でページを切り替えます。 ページ構成は `AppPage` の宣言順に一致させます
（他の UI 版と同一の並び・同一の設定ファイルを共用します）。

| ページ | 内容 |
| --- | --- |
| キャプチャ | 撮影（スクリーン / ウィンドウ / 範囲）、切り出し、ズーム操作、プレビュー、ステータス |
| フォルダビュー | 保存先フォルダの画像のサムネイル一覧 |
| Undo 一覧 | 編集履歴のサムネイル一覧 |
| 設定 | テーマ / 保存 / 画像 / キャプチャ / 矩形選択範囲の制限 / ホットキー / 外観 |

- ナビゲーション ペインの開閉は設定（`IsNavigationExpanded`）へ保存し、次回起動時に復元します。
- ページの内容は選択時に初めて生成し、以降は同じ要素を表示します（ページの状態と購読を保持するため）。

### 3.1 キャプチャ ページ

| 要素 | 仕様 |
| --- | --- |
| 保存 | 現在のプレビュー画像をファイルへ書き込む。 形式は拡張子から判別する。 同名ファイルがある場合は上書き確認ダイアログを表示する |
| コピー | 現在のプレビュー画像をクリップボードへコピーする |
| 貼り付け | クリップボードの画像をプレビューへ読み込む |
| スクリーン選択 | カーソル下のモニター全体をキャプチャする（クリックまたは Enter で確定） |
| ウィンドウ選択 | カーソル下のウィンドウをキャプチャする（クリックまたは Enter で確定） |
| 範囲選択 | ドラッグで指定した矩形をキャプチャする（Enter で確定 / Escape でキャンセル） |
| 自動切り出し | 線検出によりウィンドウ枠を推定し、切り出し範囲を提示する。 再実行で確定 / モード外のダブルクリックと Escape でキャンセル |
| 切り出し | プレビュー上のドラッグで現在の画像を切り出す（`Ctrl+R` / ツールバーの切り出しボタン / メニューで開始。 再押下で確定 / 選択なしでキャンセル） |
| 戻す / やり直し | 編集履歴を移動する（撮影・切り出しの直前へ戻せる。 画像がない場合は無効） |
| プレビュー | 画像をズーム・パンして表示する（ドラッグでパン / Ctrl+ホイールでズーム） |
| ズーム操作 | ⊖ / ⊕ / Fit ボタンと拡大率のスライダ・表示（画像未設定時は可否が false） |
| 検出矩形 | 自動切り出しの検出結果を**水色の実線枠**（2 DIP）でオーバーレイ表示する。 ホバー中の矩形（面積が最小のもの）は**赤色**で強調する |
| ルーペ | 切り出し中のみカーソル位置を拡大し、カーソルの右下（設定のオフセット）へ追従する。 切り出しを確定・キャンセルすると消える |
| 選択矩形の破線 | 撮影・切り出しの選択中は、ルーペ画像へ選択矩形の破線（2 色交互）を重ねる。 色は設定 `LoupeSelectionRectColorA` / `LoupeSelectionRectColorB` |
| ステータス | カーソル座標 / 画像サイズ / 保存状態 / 保存ファイル名 / 通知メッセージを表示する |

通知メッセージの文言（撮影・切り出し・貼り付け・保存失敗・自動切り出し）と、それを設定する操作は
`StatusMessages`（App.Core）と `MainViewModel` が単一所有します（UI 層は結果の表示だけを担う）。

**ウィンドウ（タスク バー）アイコン**は他の UI 版と同じ Fluent アイコン（`ic_fluent_scan_table_24_regular.svg`）です。 WinUI 3 の `AppWindow.SetIcon` はアイコン ファイルのパスしか受け付けないため、共有 SVG から複数サイズ（16〜256）の ICO を実行時に組み立てて一時ファイル（`%TEMP%\SaveEvidence\app-icon.ico`）へ書き、そのパスを渡します（`WindowIconFile`）。 書き出せない場合は既定のアイコンのまま動作します。
**ツールバーの構成**は他の UI 版と同じです（☰ メニュー / ファイル名テンプレート / 保存 / 撮影 3 種 / 切り出し。 区切りは縦線）。
元に戻す・やり直しは ☰ メニューから実行します。 ツールバーとステータス バーは、置く要素（ボタン 32 DIP・
スライダ 24 DIP）より少しだけ高い行にし、要素を垂直方向中央へ揃えます。
| メニュー | ツールバー左端の ☰ から、保存・コピー・貼り付け・履歴・撮影・切り出しの各コマンドを選べる。 保存・撮影・切り出しにはツールバーと同じ SVG アイコンを表示する。 ショートカットは表示のみ |

- ファイル名テンプレートはツールバーの入力欄で編集します（設定ページにはありません）。 入力欄は文字列の実測幅に合わせて広がり、上限は**右の要素が隠れない幅**（ツールバーの幅から他の要素・余白・間隔を除いた幅・最小 100 DIP）です。
  テンプレートが不正な場合は入力欄の枠が赤色になります。

### 3.2 キャプチャ選択の操作

| 種別 | 選択中の表示 | 確定 | キャンセル |
| --- | --- | --- | --- |
| スクリーン選択 | カーソル下のモニターをハイライト（他は暗転） | 左クリック / Enter | Escape / 非アクティブ化 |
| ウィンドウ選択 | カーソル下のウィンドウをハイライト（他は暗転） | 左クリック / Enter | Escape / 非アクティブ化 |
| 範囲選択 | 全面暗転 + 選択枠 + ドラッグハンドル + 座標ラベル + ルーペ | Enter | Escape |
| 自動切り出し | 検出矩形を水色の実線枠で表示（ホバー中は赤枠） | 矩形内のダブルクリック | 矩形外のダブルクリック / Escape |

- 確定は**左ボタンのみ**を受け付けます。
- 他のウィンドウへ切り替わった（オーバーレイが非アクティブになった）場合はキャンセルします。
- 撮影は 1 件ずつ実行します（実行中に再要求しても無視します）。

### 3.3 切り出しの操作

| 操作 | 挙動 |
| --- | --- |
| 開始 | 切り出しの選択オーバーレイを表示し、ルーペを有効にする（画像が無い場合は開始しない） |
| 確定 | Enter / 確定操作で、選択した矩形を元画像から切り出す |
| キャンセル | Escape / 選択なしでの再操作で、切り出しを取り消す（画像は変更しない） |
| 履歴 | 確定時は切り出し**前**の画像を履歴へ積む（「戻す」で戻せる） |

### 3.4 ホットキー

| 種別 | 既定値 |
| --- | --- |
| スクリーン選択 | `Ctrl + Shift + Q` |
| ウィンドウ選択 | `Ctrl + Shift + W` |
| 範囲選択 | `Ctrl + Shift + E` |

- 設定ページで変更できます（入力欄へフォーカスして修飾キー付きのキーを押す / テキスト入力 / クリア）。
- **変更は次回起動時に反映されます**（OS への登録は起動時に 1 度だけ行います）。
- 他のアプリが同じ組み合わせを使用している場合は、そのホットキーだけが機能しません（アプリは継続します）。

## 4. 一覧ページ

### 4.1 フォルダビュー ページ

| 要素 | 仕様 |
| --- | --- |
| 対象 | 保存先フォルダ（設定 `SaveFolderPath` の解決結果）の画像ファイル |
| 表示モード | 特大 / 大 / 中。 サイズは設定の `FolderExtraLargeIconSize` / `FolderLargeIconSize` / `FolderMediumIconSize`。 `Settings.FolderViewModeIndex` へ保存する |
| ソート順 | 名前の昇順（▲）/ 降順（▼）。 大文字小文字は区別しない。 `Settings.FolderViewSortAscending` へ保存する |
| 最新の情報に更新 | 一覧を再読み込みする（**ツールバーの先頭**。 表示モード・ソート順の左。 4 UI 版で同じ並び） |
| 一覧の折り返し | ウィンドウ幅に合わせて列数を変える（列数は固定しない） |
| ダブルクリック | そのファイルを OS の既定アプリで開く |
| 一覧アイテム | 画像を縦横比のまま正方形の枠へ収める。 マウスを重ねると枠が青になり背景が薄いグレーになる |
| 一覧の背景 | 一覧の領域だけをグレーで塗る（明色 `#F2F2F2` / 暗色 `#2B2B2B`。 色は `AppPalette.ListBackground`（App.Core）が単一所有し、4 UI 版で同じ） |
| ステータス | アイテム数 / 現在の表示モード / ソート状態を左寄せ、フォルダ パスを右寄せで表示する |

- 一覧はページを表示するたびに再読み込みします（他のプロセスがファイルを増やした場合にも追従）。
- ページ表示時に保存済みの表示モード・ソート順を復元し、ボタンの選択状態も同期します。
- 読み込めないファイル（破損・アクセス拒否）は代替画像を表示し、項目自体は残します。
- サムネイルは背景で生成し、見えている項目を優先します（表示中は並列、非表示中は 1 件ずつ）。
- 一覧の幅は**画像の縦横比**で決まります（幅は表示モードの一辺に固定し、高さを縦横比から求める。 高さは項目を作る時点で決めるため、画像の生成後に大きさは変わりません）。 **行の高さは行内の最大アイテム高さ**になり、アイテムは行内で**下端揃え**になるため、ファイル名の位置が行内で揃います（AvaloniaUI 版と同じ並べ方）。
- **影は画像（枠）に付けます**（項目全体には付けません）。 幅・濃さの変化は `ShadowPlan`（`App.Core`）が単一所有し、寸法は `ThumbnailTileMetrics`（`App.Core`）が単一所有します。 一覧の隅は `CornerStops` の放射グラデーション（要素を並べるため）で塗ります。 キャプチャページの画像は `ZoomViewControl.SetShadow` が Composition の `DropShadow` を付けます（ぼかしの広がりと濃さは `ShadowPlan` が単一所有する）。

### 4.2 Undo 一覧ページ

| 要素 | 仕様 |
| --- | --- |
| 表示順 | Redo（新しい未来）→ 現在 → Undo（古い過去）の固定 |
| 現在の画像 | **ラベルを太字**にして示す（枠・影・ホバーはフォルダビューと同一）。 画像が未設定の場合は項目を作らない |
| サムネイル | 画像を縦横比のまま表示する（幅は表示モードの一辺、高さは縦横比から決める） |
| ラベル | `やり直し N` / `現在` / `元に戻す N` |
| 表示モード | 特大 / 大 / 中。 `Settings.UndoViewModeIndex` へ保存し、次回起動時に復元する（**「最新の情報に更新」は置かない**。 履歴は編集のたびに更新されるため。 4 UI 版で同じ並び） |
| 一覧の折り返し | ウィンドウ幅に合わせて列数を変える（行の高さは行内の最大アイテム高さ・下端揃え） |
| ダブルクリック | その画像を一時ファイル（PNG）へ書き出し、OS の既定アプリで開く |
| 一覧の背景 | 一覧の領域だけをグレーで塗る（明色 `#F2F2F2` / 暗色 `#2B2B2B`。 色は `AppPalette.ListBackground`（App.Core）が単一所有し、4 UI 版で同じ） |
| ステータス | アイテム数 / 現在の表示モードを左寄せ、操作方法のヒントを右寄せで表示する |

> **制約**: サムネイルは編集履歴が保持する画像を参照するだけで、破棄しません。
> 履歴は撮影・切り出しの直前に現在の画像を退避することで蓄積します。

### 4.3 設定ページ

設定は変更のたびに即時保存します（保存ボタンはありません）。

| セクション | 項目 |

| キャプチャ設定 | キャプチャ時にメイン ウィンドウを隠す |
| 矩形選択範囲の制限 | 画像外の選択を禁止（境界内にクリップ） |
| ホットキー設定 | スクリーン・ウィンドウ・範囲選択の 3 種（入力欄 + クリア ボタン） |
| 外観設定 | 下記の 7 カテゴリ（色は色ピッカー、数値は増減入力）。 見出し右端に「デフォルト値に戻す」 |

「外観設定」のカテゴリと項目の順序は他の UI 版と同じです。

| カテゴリ | 項目 |
| --- | --- |
| ラベル設定 | 選択矩形のサイズを表示 / 矩形操作を矩形内に表示 / 選択中のウィンドウのタイトルを表示 / 矩形操作時にカーソル位置の座標をカーソル横に表示 / ルーペの中心座標をルーペ上部に表示 |
| 選択枠・暗転 | 選択枠の色 / 選択枠の太さ / 選択矩形の最小サイズ / 暗転オーバーレイの色 |
| ドラッグハンドル・マーカー | ハンドルの色 / ハンドルのサイズ / ハンドル判定半径 / マーカーの色 / マーカーの長さ |
| ルーペ | 枠色 / 枠の太さ / 十字線色 / 画像外の色 / 選択矩形破線の色A / 選択矩形破線の色B / 拡大率 / サイズ / カーソルからのオフセット |
| 選択矩形内のラベル | 1〜3 行目のテキスト色 / 背景色 / フォントサイズ |
| カーソル位置の座標ラベル | テキスト色 / 背景色 / フォントサイズ |
| ルーペの中心座標ラベル | 座標ラベルのテキスト色 / 背景色 / フォントサイズ |

- 数値入力は範囲を制限し、範囲外の値は入力できません。
- 色は `#AARRGGBB` で保持し、色ピッカーの隣に現在値を表示します（クリックで色ピッカーを開く）。
- ファイル名テンプレートはキャプチャ ページのツールバーで編集します（設定ページにはありません）。

## 5. 画像の保存仕様

保存形式（拡張子からの判別）とエンコードはコアの画像ライターが単一所有します（各 UI で同じ結果にする）。

| 拡張子 | 保存形式 |
| --- | --- |
| `.bmp` | Windows Bitmap |
| `.png` | PNG |
| `.jpg` / `.jpeg` | JPEG |
| `.gif` | GIF |
| `.tif` / `.tiff` | TIFF |

- 拡張子の大文字・小文字は区別しません（`.PNG` も PNG として保存）。
- **上記以外の拡張子は保存できません**（`NotSupportedException`）。 PNG 等へ黙って差し替えると、意図と違う形式のファイルができて気付かないためです。
- JPEG / BMP はアルファ（透明度）を保存できません（形式の仕様。 透過を保つには PNG を選びます）。
- 生成したファイル名のファイルが既に存在する場合は、**上書き確認ダイアログ**（「はい」/「いいえ」）を表示します。
  キャンセル（「いいえ」・Esc・ダイアログを閉じる）した場合は保存しません。
- 保存に成功すると、ファイル名テンプレートの右端の数値を +1 します（次回は別名になる）。

## 6. クリップボード

| 操作 | 仕様 |
| --- | --- |
| コピー | プレビュー画像を PNG としてクリップボードへ置く。 アプリの終了後も貼り付けられるよう内容を確定する |
| 貼り付け | クリップボードに画像がある場合は読み込んでプレビューへ設定する。 無い場合は何もしない |

- クリップボードは他のプロセスと共有するため、使用中の失敗は例外にせず（通知を出さず）ログへ記録します。

## 7. 設定ファイル

| 項目 | 仕様 |
| --- | --- |
| パス | `%LOCALAPPDATA%\SaveEvidence\settings.json` |
| 共有 | 他の UI 版と**同一ファイル**を共用する |
| 互換性 | enum は名前で保存する。 UI 間で読み書きしても値が変わらない |

### 7.1 ウィンドウ配置の保存・復元

| タイミング | 挙動 |
| --- | --- |
| 起動 | `MainWindowBounds`（画面物理ピクセル）と `MainWindowState` を読み、位置・サイズ・最大化状態を復元する。 `IsNavigationExpanded` でナビの開閉も復元する |
| 終了 | 現在の位置・サイズ・表示状態とナビの開閉を保存する（最小化中は位置とサイズを更新しない） |

- 幅・高さが 0 以下の値（壊れた設定ファイル・手編集の誤り）では復元しません。
- 保存に失敗しても終了は妨げません（原因だけをログへ記録します）。

## 8. ログ

| 項目 | 仕様 |
| --- | --- |
| 出力先 | `%LOCALAPPDATA%\SaveEvidence\logs\SaveEvidence<日付>.log` |
| 保持 | 日次ローテーション・7 日 |
| 接頭辞 | `[App.WinUI3]` |

記録する事象は、起動 / 終了 / 未処理の例外 / 設定変更の撮影セッションへの反映失敗 / ウィンドウ配置の保存失敗 /
一覧の読み込み失敗 / サムネイル生成の失敗 / ホットキーの登録失敗 / 受信の開始失敗 / クリップボード操作の失敗です。

## 9. 公開 API

`App.WinUI3` は**アプリ（実行ファイル）**のため、外部から参照できる公開 API を持ちません。
利用者と別 UI の実装者が使う公開 API は、共有する下位層が所有します。

| 層 | 提供するもの |
| --- | --- |
| `App.Core` | 設定・ViewModel・画像のコンテナ・保存の実装。 サムネイル生成のスケジューラと優先度・容量制限付きキャッシュ・画像拡張子の判定・表示モードの文言・設定の写像は**内部型**（`InternalsVisibleTo`）として本アプリが使う |
| `Parts.CapturePreview.Core` | 撮影・切り出しの共通規則と外観設定の型 |
| `Parts.CapturePreview.ControlWinUI3` | 撮影セッション・切り出しビュー・選択オーバーレイのコントロール |
| `Platform.WinUI3` | コア型と WinUI 3 型の相互変換・描画リストの要素への反映・Composition の画像表示 |

## 10. エラー時の挙動

| 事象 | 挙動 |
| --- | --- |
| 撮影の失敗（画面取得不可・要素検出の失敗） | アプリを継続する（原因は撮影スタックが既に記録する）。 プレビューは変更しない |
| 保存の失敗（未対応の拡張子・書き込み不可） | アプリを継続する。 失敗の内容は通知メッセージまたはログで確認できる |
| 一覧の読み込みの失敗 | 空の一覧を表示し、原因をログへ記録する |
| サムネイル生成の失敗 | 代替画像を表示したままにし、原因をログへ記録する |
| クリップボード操作の失敗 | 何も変更せず、原因をログへ記録する |
| ホットキーの登録失敗 | そのホットキーだけが機能しない（アプリは継続する）。 原因をログへ記録する |
| UI スレッドの未処理例外 | 記録したうえでアプリを継続する（ウィンドウの表示を維持する） |
| アプリ全体の未処理例外 | 記録してからプロセスが終了する |

## 11. 制限事項

| 制限 | 内容 | 理由 |
| --- | --- | --- |
| ヘッドレスでの UI 検証 | XAML の型をウィンドウなしで生成できないため、画面の組み立てそのものは自動テストの対象外です | 実行環境の制約（[`SPEC_System.md`](SPEC_System.md) の「テストできない範囲」を参照） |
| ホットキーの反映 | 設定の変更は次回起動時に反映されます | OS への登録は起動時に 1 度だけ行うため |
| ツールバーの折り返し | ウィンドウ幅より広い場合はツールバーが横スクロールになります（他の UI 版は折り返し） | WinUI 3 の標準パネルに任意の大きさの子を折り返すパネルが無いため |
| サムネイルの形 | 一覧のサムネイルは幅を表示モードの一辺に固定し、高さを画像の縦横比から決めます。 行の高さは行内の最大アイテム高さで、アイテムは下端揃えです | AvaloniaUI 版と同じ並びにするため |
| 一覧の共通化 | フォルダビューと Undo 一覧は同じ `ThumbnailList`／`ThumbnailTileView` を使います。 影・名前の行・ホバー・間隔（隣り合う画像は 28 DIP）はそこで単一所有します | 2 つのページで見た目がずれないようにするため |
| ホバー | マウスが重なると項目全体へ薄いグレーの帯（`#DADADA`）を出し、影を消します | AvaloniaUI 版と同じ見た目にするため |
| サムネイルの影 | 画像の周りに枠線・下地は置かず、**影だけ**を付けます。 `UIElement.Shadow`（`ThemeShadow`）は一覧では描かれず、合成の `DropShadow` を子ビジュアルへ置くと影が画像の上へ描かれるため、画像の外側へ `ThumbnailTileMetrics.ShadowAlphaAt`（4 UI 版で共通）の濃さを写したグラデーションを貼ります | 縮小キャンバス（`SwapChainPanel`）の内容は XAML 要素より背面に合成されるため、画像の領域へ半透明の塗りを重ねると画像が隠れます（実測） |
| 同時実行 | 撮影は 1 件ずつです（実行中の再要求は無視します） | オーバーレイが重なるのを防ぐため |
| 配布 | 1 ファイルの自己完結発行で配布します（AOT のフォルダー配布も別途作れます。 どちらも事前インストール不要） | 発行設定と配布物の定義はリポジトリのスクリプト・設定が単一所有するため |
| 起動方法 | 実行ファイル（アプリ ホストの exe）から起動します。 `dotnet <アプリ>.dll`（.NET ホスト経由）では起動できません | アンパッケージの WinUI 3 アプリは、マニフェストによるアクティベーションと `resources.pri` の解決をアプリ ホストの exe が担うため（`0xC000027B` で即座に終了します。 実測 2026-10-17） |
| タイトルバー | 自前の帯を作らず、**タイトル バーの位置にツールバーを表示**します（他の UI 版と同じ）。 クライアント領域をタイトル バーへ拡張し（`ExtendsContentIntoTitleBar`）、上端 32 DIP の帯を押したらポインターの移動量から `AppWindow.Move` で位置を更新します（ダブルクリックで最大化） | **ウィンドウ操作ボタンは自前で置きません**（拡張しても標準のボタンが描画されるため、重ねると 2 重に見えます。 実測 2026-10-17）。 タスクバーの表示は `Window.Title`（`SaveEvidence`）が担います |
| アプリ名の位置 | 左上のアプリ アイコンの**すぐ右**へ置き、縦位置をアイコンと揃えます（アイコンと同じ行の 2 列目。 左の余白を 8 DIP 詰めます）。 展開時だけ表示します | 他の UI 版と同じ位置に揃えるため、ペインの見出し（`PaneHeader`）は使いません |
| ナビゲーションの幅・文字サイズ | 展開 136 / 収納 40 DIP・項目の文字サイズ 14 DIP（`NavPanelMetrics`（App.Core）が単一所有） | UI 版ごとに幅・文字の大きさがずれないようにするため。 140 未満だと最も長い「フォルダビュー」が省略記号になります（実測） |
| テーマの適用範囲 | ルート要素（ウィンドウ全体）へ `RequestedTheme` を設定します。 併せてルートの下地を `AppPalette`（App.Core）の色で塗り、ナビゲーション ペインの背景は `ThemeDictionaries`（Light / Dark / Default）で与えます | ナビゲーションだけに適用すると、ツールバー・ステータス バー・ページが明色のまま残り暗色テーマで色が混ざります（実測）。 ペイン背景は `Resources` への単純な代入ではテーマ変更時に解決し直されず、暗色へ切り替えても明色のまま残ります（実測。 `ThemeDictionaries` に入れると追随します） |
| テーマの判定 | 明示指定（ライト / ダーク）は要求値で判定し、`システム` だけ OS のアプリ用テーマ（レジストリ）で判定します | 読み込み前の `ActualTheme` は既定（明色）を返すため、暗色で起動するとナビゲーション パネルが明色で塗られテーマと逆になります（実測） |
| ナビゲーション開閉ボタンのアイコン | 左上（アプリ アイコンの下）へ自前のボタン（他 UI 版と同じ SVG アイコン）を置きます | 標準の `NavigationView` のボタンはアイコンを差し替えられないため使わない |
| ツールバーの横スクロール | 無効にします（`HorizontalScrollBarVisibility` / `HorizontalScrollMode` を `Disabled`） | 有効のままだと、ツールバーの余白をクリックした操作で内容が横へ流れ、左端のメニュー ボタンが隠れます（実測） |
| ナビゲーションの構成 | 収納時はアイコン列、展開時はページ領域の上へ**自前の一覧**（アイコン + 文字・選択中の背景と左端の青いマーク）を重ねます。 ページ領域は左の 40 DIP の列の右に置き、開閉で動きません | `NavigationView` はペインの展開が窓の幅・DPI・テーマで崩れ（ラベルが出ない・内容が上端から始まらない。 実測）、収納時の項目位置も固定できないため使いません |
| フッター | 展開時の一覧の下端へ UI 名と実際のバージョン（`WinUI3  v0.1.0`）を表示します | `AppVersion`（App.Core）が表記を単一所有します |
| ウィンドウの最小サイズ | `OverlappedPresenter.PreferredMinimumWidth` / `PreferredMinimumHeight` で枠を含む **640 × 400 DIP** に制限します（DPI 倍率を掛けて画面物理ピクセルで指定する） | プロパティは画面物理ピクセルで解釈されるため、125% では 800 × 500 ピクセルに換算します |
| ウィンドウ配置の復元 | 保存値が画面外（撮影中の退避先など）なら復元せず、最小化は通常表示として復元します | 復元可否は `WindowPlacementRule`（App.Core）が単一所有します |
