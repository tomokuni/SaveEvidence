## 1. 対象利用者

- `App.MewUI` を起動して画面キャプチャを行う**エンドユーザー**
- 同じコア（`App.Core`）を使う**別 UI の実装者**（Avalonia 版 `App.AvaloniaUI` / 将来の UI）

## 2. 起動要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10 以降 |
| ランタイム | .NET 10（デスクトップ） |
| グラフィックス | Direct2D バックエンド + Win32 プラットフォームホスト（起動時に登録） |

`App.MewUI` は **GUI アプリ（WinExe）** です。 コンソール出力は持ちません。

- **タイトル バーの帯は作りません**（ページ領域はクライアント領域の先頭から始まります）。 左上には、タスク バーと同じアプリ アイコンだけを置きます。 押下すると「元のサイズに戻す / 移動 / サイズ変更 / 最小化 / 最大化 / 閉じる」のメニューを出します（項目と並びは `WindowMenu`（App.Core）が単一所有する）。
- **ナビゲーション パネル**はページ領域の上へ重なり（上端はページ領域の先頭、下端はステータス バーに被る）、一番上にアプリ アイコン、その下に開閉ボタン（アイコンのみ。 開いているとき `ic_fluent_panel_left_contract_24_filled.svg`、閉じているとき `ic_fluent_panel_right_contract_24_filled.svg`）を置きます。 **展開時は開閉ボタンの右にアプリ名（SaveEvidence）**を表示します。 展開しても**ページ領域は動きません**。
- 展開中に**ナビ領域の外**（ページ領域・タイトル バー相当の上端・ウィンドウの外）を操作すると収納へ戻ります。
- ウィンドウの**最小サイズ**と**既定サイズ**は 700 × 400 DIP です（`WindowMetrics`（App.Core）が単一所有する）。

## 3. 画面仕様

左ペイン（`NavigationView`）でページを切り替えます。 ページ構成は `AppPage` の宣言順に一致させます
（Avalonia 版と同一の並び・同一の設定ファイルを共用します）。

| ページ | 内容 | 状態 |
| --- | --- | --- |
| キャプチャ | 撮影（スクリーン / ウィンドウ / 範囲）、切り出し、ズーム操作、プレビュー、ステータス | 実装済み |
| 画像の影 | プレビュー画像・フォルダビュー・Undo 一覧のサムネイルの 4 辺・4 隅へ、`ShadowPlan`（App.Core）の計画どおりの影を描く（`ShadowRenderer` → `SkiaShadowRenderer`（Platform.Skia）。 1 画素の帯を単色で塗るだけで、隅は画像の隅の頂点からの斜めの距離で濃さを決める。 プレビューは `ZoomViewControl.SurroundRenderer` が画像と同じ描画面へ先に描く） | 実装済み |
| フォルダビュー | 保存先フォルダの画像のサムネイル一覧 | 実装済み |
| Undo 一覧 | 編集履歴のサムネイル一覧 | 実装済み |
| 設定 | テーマ / 保存 / 画像 / キャプチャ / 矩形選択範囲の制限 / ホットキー / 外観（セクションごとに枠で囲んで表示する。 Avalonia 版と同じ構成） | 実装済み |

- **ナビゲーション項目の高さ**は 40 DIP で固定します（アイコンだけの収納時と、アイコン + 文字の展開時で高さが変わりません。 AvaloniaUI 版と同じ）。

### 3.1 キャプチャページ

| 要素 | 仕様 |
| --- | --- |
| 保存 | 現在のプレビュー画像をファイルへ書き込む。 形式は拡張子から判別する。 同名ファイルがある場合は上書き確認ダイアログを表示する |
| コピー | 現在のプレビュー画像をクリップボードへコピーする |
| 貼り付け | クリップボードの画像をプレビューへ読み込む |
| スクリーン選択 | カーソル下のモニター全体をキャプチャする（クリックまたは Enter で確定） |
| ウィンドウ選択 | カーソル下のウィンドウをキャプチャする（クリックまたは Enter で確定） |
| 範囲選択 | ドラッグで指定した矩形をキャプチャする（Enter で確定 / Escape でキャンセル） |
| 自動切り出し | 線検出によりウィンドウ枠を推定し、切り出し範囲を提示する。 再実行で確定 / モード外のダブルクリックと Escape でキャンセル |
| 切り出し | プレビュー上のドラッグで現在の画像を切り出す（`Ctrl+R` / ツールバーの切り出しボタン / メニューで開始。 再押下で確定 / 選択なしでキャンセル） |
| 戻す / やり直し | 編集履歴を移動する（撮影・切り出しの直前へ戻せる。 画像がない場合は無効） |
| プレビュー | 画像をズーム・パンして表示する（ドラッグでパン / Ctrl+ホイールでズーム）。 詳細は [`../../Parts.CapturePreview.ControlMewUI/docs/SPEC_API.md`](../../Parts.CapturePreview.ControlMewUI/docs/SPEC_API.md) |
| ズーム操作 | ⊖ / ⊕ / Fit ボタンとズーム率の表示（画像未設定時は可否が false） |
| 検出矩形 | 自動切り出しの検出結果を**水色の実線枠**（2 DIP。 Avalonia 版と同じ）でオーバーレイ表示する。 ホバー中の矩形（面積が最小のもの）は**赤色**で強調する |
| ルーペ | 切り出し中のみカーソル位置を拡大し、カーソルの右下（設定のオフセット）へ追従する。 切り出しを確定・キャンセルすると消える。 詳細は [`../../../../EsUtil/src/EsUtil.Feature.Loupe.ControlMewUI/docs/SPEC_API.md`](../../../../EsUtil/src/EsUtil.Feature.Loupe.ControlMewUI/docs/SPEC_API.md) |
| 選択矩形の破線 | 撮影・切り出しの選択中は、ルーペ画像へ選択矩形の破線（2 色交互）を重ねる。 色は設定 `LoupeSelectionRectColorA` / `LoupeSelectionRectColorB`。 詳細は [`../../Parts.CapturePreview.ControlMewUI/docs/SPEC_API.md`](../../Parts.CapturePreview.ControlMewUI/docs/SPEC_API.md) |
| ステータス | 画像サイズ / 保存状態 / 通知メッセージを表示する |

### 3.2 キャプチャ選択の操作

| 種別 | 選択中の表示 | 確定 | キャンセル |
| --- | --- | --- | --- |
| スクリーン選択 | カーソル下のモニターをハイライト（他は暗転） | 左クリック / Enter | Escape / 非アクティブ化 |
| ウィンドウ選択 | カーソル下のウィンドウをハイライト（他は暗転） | 左クリック / Enter | Escape / 非アクティブ化 |
| 範囲選択 | 全面暗転 + 選択枠 + ドラッグハンドル + 座標ラベル + ルーペ | Enter | Escape |
| 自動切り出し | 検出矩形を水色の実線枠で表示（ホバー中は赤枠） | 矩形内のダブルクリック | 矩形外のダブルクリック / Escape |

- 確定は**左ボタンのみ**を受け付けます（右クリックでは確定しません。 Avalonia 版と同じ）。
- 要素を検出できない位置（ウィンドウ選択でデスクトップ上など）をクリックした場合は確定しません（誤クリックで撮影を取りこぼさない）。
- 他のウィンドウへ切り替わった（オーバーレイが非アクティブになった）場合はキャンセルします（最前面のオーバーレイが残り続けるのを防ぐ）。
- 表示中はタスクバー・Alt+Tab の一覧に出しません（一時的な表示のため）。

### 3.3 選択中のラベル

選択矩形の左上に行を縦に積んで表示します（背景付き）。 サイズラベルは提示層（`EsUtil.Feature.Marquee.Presenter` の `MarqueePresenter`）が文言と実寸からの配置を単一所有し、コントロールがテキスト要素として表示します。 操作・情報ラベルはアプリ固有の付加情報のため、ホストが `SelectionOverlayOptions.Labels` の外観で描き、文言は `CaptureLabelTexts`（`Parts.CapturePreview.Core`）が与えます。

| 行 | 内容 | 表示条件 | 設定 |
| --- | --- | --- | --- |
| 1 行目 | サイズラベル（`(左, 上) - (右, 下), (幅×高), DisplayScale: (倍率%)`） | 設定 `SizeLabelVisible` が true で選択があるとき | 文字サイズ / 文字色 / 背景色 |
| 2 行目 | 操作ラベル（モード別の確定・キャンセル方法） | 設定 `ShowSubLines` が true のとき | 文字サイズ / 文字色 / 背景色 |
| 3 行目 | 情報ラベル（ウィンドウ選択のときのウィンドウタイトル） | 設定 `InfoLabelVisible` が true でタイトルが取得できたとき | 文字サイズ / 文字色 / 背景色 |

座標・幅×高は画像ピクセル（= 画面物理ピクセル）で表示します。 `DisplayScale` は選択位置のモニターの実表示スケール（125% スケーリングなら `125%`）を表示します。

- 座標は画像ピクセル（対象座標）で表示します（表示倍率に依存しません）。
- 日本語を含む文言は字形を持つフォントへ自動でフォールバックします（豆腐（□）にならない）。

- キャプチャ中は設定 `HideMainWindowOnCapture` に従ってメインウィンドウを**画面外へ退避**し、オーバーレイを表示します。
  - **自ウィンドウの写り込み防止**: 退避は非表示（`Hide`）ではなく位置の変更（画面外配置）です。 非表示は復帰時のウィンドウ再作成でちらつくためです（Avalonia 版と同じ方式）。 併せて `SetCaptureExclusion`（`WDA_EXCLUDEFROMCAPTURE`）を設定し、撮影後に解除します。
  - **オーバーレイ表示時のちらつき防止**: 透明な状態でオーバーレイを表示し、撮影画像が合成されたフレームで透明を解除します（表示直後に背景色の面が見えるのを防ぐため。 背景色は撮影画像の平均色に合わせます）。
- **対象は全モニター（仮想スクリーン）** です（1 モニターに限定すると、カーソルのあるモニターでしか選択できないため）。
- 確定した画像はプレビューへ設定され、撮影前の画像は Undo 履歴へ退避されます（ステータスに「キャプチャしました（W x H）」を表示）。
- 通知メッセージの文言（撮影・切り出し・貼り付け・保存失敗・自動切り出し）と、それを設定する操作は `StatusMessages`（App.Core）と `MainViewModel` が単一所有します（UI 層は結果の表示だけを担います）。
- **設定の変更は即時反映されます**: 設定画面での変更は Facade（`CaptureSessionControl.AppearanceSettings`）へ渡り、部分更新・検証・同値スキップ・適用ログはコアが担います。 実行中の切り出しセッションへは即時反映され（枠線・最小サイズ・ルーペ等）、撮影は開始時の値を使います（モーダル全画面のため）。

### 3.4 ホットキー

設定のホットキーでアプリが非アクティブでも撮影を開始できます（押下時はツールバーのボタンと同じ経路）。
未設定（キーなし）のホットキーは登録されません。

## 4. プレビューの切り出し

ツールバーの「切り出し」ボタンで、プレビューの上へ選択オーバーレイ（全面暗転 + 選択枠 + ルーペ）を重ねます。

- もう一度押すと選択領域で切り出し、選択がない状態で押すとキャンセルします。
- 切り出しは「自動切り出し」と同じ経路（Undo 退避 → 画像差し替え）を通ります。
- ズーム・パンすると座標変換が追従しますが、選択は破棄されます（座標系が変わるため）。
- 選択中はサイズラベル（画像ピクセルの座標とサイズ）と操作ラベル（ダブルクリックで確定 / 矩形外クリックでキャンセル）を行で表示します。

### 4.1 編集履歴（戻す / やり直し）

| 要素 | 仕様 |
| --- | --- |
| 戻す | 撮影・切り出しの直前の画像へ戻す（現在の画像はやり直し側へ退避される） |
| やり直し | 「戻す」で取り消した画像を再適用する |
| 有効条件 | プレビュー画像があること（履歴が空の場合は何もしない） |
| 保持段数 | 最大 5 段（超過時は最古の画像から破棄される） |
| 保存状態 | 履歴から復元した画像は未保存として扱う |

- 履歴の実体は共通コアの `UndoHistory` が保持し、UI はその操作とプレビューの差し替えのみを担います。
- 差し替え前の画像の破棄は`MainViewModel`（`PreviewImage` の所有者）が行います。

## 5. 操作ログ

マウス・キーの操作ログを Avalonia 版と同一のファイルへ出力します（Serilog）。

| 項目 | 仕様 |
| --- | --- |
| 出力先 | `%LOCALAPPDATA%\SaveEvidence\logs\SaveEvidence.log`（日次ローテーション・7 日保持） |
| 書式 | `{時刻} [{レベル}] [{カテゴリ}] {メッセージ}`（Avalonia 版と同一） |
| カテゴリ | 出力元のクラス名（`Program` / `CaptureSessionControl` / `MarqueeControl` 等） |
| 内容 | アプリ起動・終了 / 撮影の開始・確定・キャンセル / 切り出しの開始・確定・キャンセル / 選択操作（MouseDown・MouseUp・DragStart・KeyDown 等） / ズーム操作（前後のズーム率） / ルーペの状態変更（表示中の選択オーバーレイ） / 未処理の例外（Critical。 アプリ全体・UI スレッド・待機されなかったタスクの 3 経路） |
| 失敗時 | ログ出力の失敗でアプリの動作を止めない（Serilog の既定動作） |

### 5.1 配布形態

| 方式 | 成果物 | 前提 |
| --- | --- | --- |
| Native AOT（既定） | exe 1 個 + ネイティブ DLL 3 個 | Visual Studio の C++ ビルドツール（`link.exe`） |
| 自己完結（フォルダー） | exe + マネージド DLL + ネイティブ DLL | なし |

- いずれも展開したフォルダーごと配置する必要があります（ネイティブ DLL は exe へ同梱できません）。
- 設定ファイルは両方式で共通です（読み書きの書式は同一）。

### 5.2 フォルダビューページ

保存先フォルダの画像をサムネイル + ファイル名で一覧表示します。

| 要素 | 仕様 |
| --- | --- |
| 一覧の対象 | 拡張子が `.png` / `.jpg` / `.jpeg` / `.bmp` / `.gif` / `.tiff` / `.tif` / `.webp` のファイル（拡張子の判定はコアが単一所有） |
| 保存先 | 設定の `SaveFolderPath`（`{MyPictures}` のプレースホルダは展開する）。 存在しないフォルダの場合は一覧を空で表示する |
| サムネイル | 表示モードのサイズへ縮小して読み込み、正方形の枠へ縦横比を保って収める（余白は背景色） |
| 表示モード | 特大 / 大 / 中。 `Settings.FolderViewModeIndex` へ保存し、表示のたびに復元する |
| ソート順 | 名前の昇順（▲）/ 降順（▼）。 大文字小文字は区別しない。 `Settings.FolderViewSortAscending` へ保存する |
| 最新の情報に更新 | 一覧を再読み込みする |
| 一覧の折り返し | ウィンドウ幅に合わせて折り返す（列数は固定しない） |
| ダブルクリック | そのファイルを OS の既定アプリで開く |
| 一覧アイテム | 画像を縦横比のまま表示し、**画像の外側へ影だけ**を付ける（枠線・下地は描かない）。 マウスを重ねると項目全体が薄いグレーの帯（`#DADADA`）でハイライトされ、影が消える（Avalonia 版と同じ） |
| 一覧の共通化 | フォルダビューと Undo 一覧は同じ `ThumbnailList` を使い、影・名前の行・ホバー・間隔（隣り合う画像は 28 DIP）をそこで単一所有する |
| 一覧の背景 | 一覧の領域だけをグレーで塗る（明色 `#F2F2F2` / 暗色 `#2B2B2B`。 Avalonia 版の `ListBox` と同じ） |
| ステータス | アイテム数 / 現在の表示モード / ソート状態を左寄せ、フォルダパスを右寄せで表示する |

- 一覧はページを表示するたびに再読み込みします（他のプロセスがファイルを増やした場合にも追従）。
- ページ表示時に保存済みの表示モード・ソート順を復元し、トグルボタンの選択状態も同期します。
- 読み込めないファイル（破損・アクセス拒否）は背景のみを表示し、項目自体は残します。

### 5.3 Undo 一覧ページ

編集履歴（`UndoHistory`）と現在の画像をサムネイルで一覧表示します。

| 要素 | 仕様 |
| --- | --- |
| 表示順 | Redo（新しい未来）→ 現在 → Undo（古い過去）の固定 |
| 現在の画像 | **ラベルを太字**にして示す（影・ホバーはフォルダビューと同一）。 画像が未設定の場合は項目を作らない |
| サムネイル | 画像を正方形の枠へ縦横比を保って収める（余白は背景色） |
| 表示モード | 特大 / 大 / 中。 `Settings.UndoViewModeIndex` へ保存し、次回起動時に復元する |
| 一覧の折り返し | ウィンドウ幅に合わせて折り返す（列数は固定しない） |
| ダブルクリック | その画像を一時ファイル（PNG）へ書き出し、OS の既定アプリで開く |
| ステータス | アイテム数 / 現在の表示モードを左寄せ、操作方法のヒントを右寄せで表示する |

> **制約**: サムネイルは `UndoHistory` が保持する画像を参照するだけで、破棄しません。
> 履歴は撮影・切り出しの直前に現在の画像を退避することで蓄積します（キャプチャページの「戻す」「やり直し」で移動できます）。

### 5.4 設定ページ

設定は変更のたびに即時保存します（保存ボタンはありません）。 **セクションとカテゴリの構成・項目は Avalonia 版と同じ**です。

| セクション | 項目 |
| --- | --- |
| 外観テーマ設定 | テーマ（ライト / ダーク / システム。 変更は即時反映） |
| 保存設定 | 保存先フォルダ（参照ダイアログ付き。 存在しない場合は赤枠で警告）。 入力欄の下にプレースホルダの例を表示 |
| 画像設定 | 画像を中央に配置（オフで左上配置）/ 起動時の画像（グラデーション画像 / 空白。 次回起動から反映） |
| キャプチャ設定 | キャプチャ時にメインウィンドウを隠す |
| 矩形選択範囲の制限 | 画像外の選択を禁止（境界内にクリップ） |
| ホットキー設定 | スクリーン・ウィンドウ・範囲選択の 3 種（入力欄へフォーカスして修飾キー付きのキーを押す / テキスト入力も解釈する / クリアボタン） |
| 外観設定 | 下記の 8 カテゴリ（色は色ピッカー、数値は増減入力）/ 見出し右端に「デフォルト値に戻す」 |

ツールバーはウィンドウ幅に合わせて折り返す（Avalonia 版と同じ `WrapPanel`。 ファイル名テンプレートが長い場合もアイコンがウィンドウ操作ボタンへ重ならない）。 ツールバーのアイコンは**通常時は下地を塗らず**、マウスを重ねると角丸の薄い矩形、押している間はさらに濃い矩形になります（`AppPalette.ToolbarButtonBackground` が単一所有）。 押下の色は MewUI 0.21.1 がツールヒントを閉じる際に押下状態を失うため、スタイル名の差し替えで表します。

☰ のメニューと拡大率メニューは、**外側をクリックすると閉じます**（メニューより背面・ページより前面に透明な覆いを置き、そのクリックで閉じる）。 さらに**ページを切り替えたとき・ウィンドウが非アクティブになったとき・Escape を押したとき**も閉じます（覆いはページの中にしか無いため、`PageContent.OnDeactivated` / `OnWindowDeactivated` で閉じる）。 メニューの開閉ボタンを続けて押したときに「閉じた直後に開き直す」ことがないよう、覆いで閉じた直後の 300 ms は開閉ボタンのクリックを無視します（押下を覆いが受け取り、その後のマウス アップで `ClickableToolTip` の補完が走るため）。 ファイル名テンプレートの入力欄は文字列の実測幅に合わせて広がり、上限は**折り返さない幅**（ツールバーの幅から他の要素と余白を除いた幅・最小 220 DIP）です。

「外観設定」のカテゴリと項目（Avalonia 版と同じ順序）。

カードは背景を持たず 1 DIP の枠だけを描きます（Avalonia 版と同じ）。
「外観設定」の本体は 3 列（カテゴリ / 項目名 / 設定値）のグリッドで、カテゴリの切れ目に横線を入れます。
行間・列間は 5 DIP、カテゴリ名はカテゴリ先頭の行へ揃えます（Avalonia 版と同じ）。

| カテゴリ | 項目 |
| --- | --- |
| ラベル設定 | 選択矩形のサイズを表示 / 矩形操作を矩形内に表示 / 選択中のウィンドウのタイトルを表示 / 矩形操作時にカーソル位置の座標をカーソル横に表示 / ルーペの中心座標をルーペ上部に表示 |
| 選択枠・暗転 | 選択枠の色 / 選択枠の太さ / 選択矩形の最小サイズ / 暗転オーバーレイの色 |
| ドラッグハンドル・マーカー | ハンドルの色 / ハンドルのサイズ / ハンドル判定半径 / マーカーの色 / マーカーの長さ |
| ルーペ | 枠色 / 枠の太さ / 十字線色 / 選択矩形破線の色A / 選択矩形破線の色B / 拡大率 / サイズ / カーソルからのオフセット |
| ルーペ | 画像外の色（`LoupePasteboardColor`） |
| 選択矩形内のラベル | 1〜3 行目のテキスト色 / 背景色 / フォントサイズ |
| カーソル位置の座標ラベル | テキスト色 / 背景色 / フォントサイズ |
| ルーペの中心座標ラベル | 座標ラベルのテキスト色 / 背景色 / フォントサイズ |

- ファイル名テンプレートはキャプチャページのツールバーで編集します（Avalonia 版と同じく設定ページにはありません）。
- 数値入力は範囲を制限し、範囲外の値は入力できません。
- 色は `#AARRGGBB` で保持し、色ピッカーの隣に現在値を表示します。
- ホットキーの変更は次回起動時に反映されます（登録は起動時）。

## 6. 画像の保存仕様

保存形式（拡張子からの判別）とエンコードはコア（`EsReadOnlyBitmap.Save` / `EsReadOnlyBitmap.Load` / `EsBitmap.Load`）が**単一所有**します（両 UI で同じ結果にする）。

| 拡張子 | 保存形式 |
| --- | --- |
| `.bmp` | Windows Bitmap |
| `.png` | PNG |
| `.jpg` / `.jpeg` | JPEG |
| `.gif` | GIF |
| `.tif` / `.tiff` | TIFF |

- 拡張子の大文字・小文字は区別しません（`.PNG` も PNG として保存）。
- **上記以外の拡張子は保存できません**（`NotSupportedException`。 例: `.webp`）。 PNG 等へ黙って差し替えると、意図と違う形式のファイルができて気付かないためです。
- エンコードの実体は `System.Drawing.Common`（.NET 標準）です（Windows 専用）。 品質の指定はできません（形式ごとの既定値）。
- JPEG / BMP はアルファ（透明度）を保存できません（形式の仕様。 透過を保つには PNG を選びます）。
- 生成したファイル名のファイルが既に存在する場合は、**上書き確認ダイアログ**（「はい」/「いいえ」）を表示します。 キャンセル（「いいえ」・Esc・ダイアログを閉じる）した場合は保存しません。
- 保存に成功すると、ファイル名テンプレートの右端の数値を +1 します（次回は別名になる）。

## 7. 設定ファイル

| 項目 | 仕様 |
| --- | --- |
| パス | `%LOCALAPPDATA%\SaveEvidence\settings.json` |
| 共有 | Avalonia 版 `App.AvaloniaUI` と**同一ファイル**を共用する |
| 互換性 | enum は名前で保存する（`JsonStringEnumConverter`）。 UI 間で読み書きしても値が変わらない |

### 7.1 ウィンドウ配置の保存・復元

| タイミング | 挙動 |
| --- | --- |
| 起動 | `MainWindowBounds`（物理px）と `MainWindowState` を読み、位置・サイズ・最大化状態を復元する。 `IsNavigationExpanded` でナビの開閉も復元する |
| 終了 | ウィンドウの実座標（位置・サイズ）と状態、ナビの開閉を設定へ書き戻す |

- 保存するサイズは**クライアント領域**（枠を除く）です。 復元時に同じ値がクライアント領域へ適用されます。
- 保存済みの位置が画面外（モニター未接続など）の場合は復元を**中止**し、既定位置で起動します。
- 座標は物理pxで保存するため、DPI やモニター構成が変わっても他 UI と同じ位置に復元されます。

> **検証時の注意**: 終了時に設定を上書きするため、動作確認でウィンドウを動かした場合は
> `settings.json` を事前に退避し、確認後に戻してください。

## 9. エラー時の挙動

| 状況 | 挙動 |
| --- | --- |
| バックエンド / プラットフォームホスト未登録 | 起動直後に例外、または無言終了（`Program` で必ず登録する） |
| 設定ファイルが無い | 既定値で起動する（`SettingsService` が生成する） |
| 設定ファイルが壊れている | 既定値へフォールバックする（`SettingsService` の仕様に従う） |
| プレビュー画像が未設定 | 何も描画しない（例外にしない） |
| モニターを検出できない | キャプチャを開始しない（プレビューを変更しない） |
| 画面の取得に失敗 | キャプチャを開始しない（オーナーウィンドウを元の表示状態へ戻す） |
| 選択が退化している（幅・高さが 1px 未満） | キャンセルと同じ扱いにする（0 サイズの画像を作らない） |
| フォルダを列挙できない | 一覧を空で表示する（ページごと落とさない） |
| 画像をデコードできない | その項目のサムネイルを描画しない（項目自体は残す） |
| グローバルホットキーの登録に失敗 | 該当のホットキーのみ無効になる（他のホットキーと操作は影響を受けない） |
