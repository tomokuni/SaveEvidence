# EsUtil.Ui.AvaloniaUI.Annotation サンプルアプリケーション

注釈レイヤーの**動作と外観を確認する**ためのサンプルです（保存は行いません）。

## 1. 概要

市松模様のサンプル画像の上に、枠線 1 件と吹き出し 1 件を置いた状態で起動します。

- **枠線**: 赤い枠・角丸（内側は塗らない）。
- **吹き出し**: 白い内側・黒い枠・しっぽ（吹き出し口）。 本文の一部だけ太字 + 赤色。
- **左の設定ペイン**: 既定値（枠線・吹き出し・本文の書式）と全体設定（行間の倍率・ハンドルの掴む半径）を変えられます。
  行の部品と色の選択はコントロールの編集 UI と同じもの（`AnnotationEditorControls` / `ColorSelectorControl`）を使います。

## 2. 使い方

```powershell
dotnet run --project src/EsUtil.Ui.AvaloniaUI/Annotation/sample/EsUtil.Ui.AvaloniaUI.Annotation.Sample.csproj
```

| 操作 | 確認できること |
| --- | --- |
| 枠線・吹き出しをクリック | 選択（**8 方向のハンドル**が Marquee の提示層で描かれる） |
| 本体をドラッグ | 移動（Marquee の通知が文書へ書き戻る） |
| ハンドルをドラッグ | サイズ変更（**ハンドルの外周を押しても選択は解除されない**） |
| しっぽの先端の円をドラッグ | 吹き出し口の移動（本体と独立。 円は当たり判定と同じ半径で描かれる） |
| **右クリック** | **外観（枠線・内側・角丸）・本文の書式（フォント・大きさ・色・B/I/U/S）・重なり順の編集** |
| ダブルクリック / Enter | **本文のその場編集**（表示中のレイアウトのままキャレットが立ち、上に書式バーが出る） |
| 左の設定ペイン | **既定値**（枠線・吹き出し・本文）と全体設定（行間・ハンドルの掴む半径）の変更。 変更後に追加した注釈へ効く |
| 「枠線を追加」「吹き出しを追加」 | 新しい注釈の追加（既定値を使う） |
| Delete | 選択中の注釈の削除 |
| 方向キー | nudge（1 px。 `Shift` 併用で 10 px） |
| ツールバーの「元に戻す」「やり直す」 / `Ctrl+Z` / `Ctrl+Y` | 変更の取り消しとやり直し（ドラッグ 1 回 = 1 手） |

**本文のその場編集**: 本文をダブルクリック（または Enter・「本文を編集」）すると、**表示中のレイアウトのまま**キャレットが立ちます。
文字を入力でき、`←→↑↓`・`Home`・`End` でキャレットを動かし、`Shift` 併用で選択します。 ドラッグでも選択できます。
日本語入力（IME）にも対応しています（変換中の文字列はキャレットの位置へ下線付きで出ます）。

**文字単位の書式（編集中）**: 文字を選び、**本文の上に出る書式バー**でフォント・大きさ・色・B / I / U / S を押すと、
**その範囲だけ**に**その場で反映**されます（選択が無ければ全体。 バーに適用先を表示します）。 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` も同じです。
バーを押しても編集は続きます（操作の後は本文へフォーカスが戻ります）。 終えるときは **「完了」**・`Ctrl+Enter`・本文の外側をクリック（`Esc` も可）。

**文字単位の書式（編集中でないとき）**: 右クリックのフライアウトの「本文の書式」は、**適用先**（選択範囲または全体）を表示してから適用します。
