# App.WinForms 外部機能仕様書

`App.WinForms`（実行ファイル `SaveEvidence.WinForms.exe`）は、Windows デスクトップ向けの画面キャプチャ アプリです。 本ドキュメントは**利用者から見た機能**（画面・操作・設定ファイル・エラー時の挙動）を記述します。

## 1. 対象利用者

Windows 上で画面の一部をすばやく切り出して保存したい利用者です。 撮影（全画面 / ウィンドウ / 範囲）→ 切り出し → 保存までを、アプリを前面に出さずにグローバル ホットキーから開始できます。

## 2. 起動要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10 以降 |
| ランタイム | .NET 10 デスクトップ ランタイム（自己完結の発行物では不要） |
| 権限 | 通常の利用者権限（管理者権限は不要） |
| 画面 | モニター単位の DPI 対応（Per-Monitor V2）で動作します |
| 書き込み先 | `%LOCALAPPDATA%\SaveEvidence\`（設定とログ）、設定で指定した保存先フォルダ |

## 3. 画面仕様

ウィンドウは左の**ナビゲーション パネル**（キャプチャ / フォルダビュー / Undo 一覧 / 設定）と右の**ページ内容**で構成します。 ナビゲーション パネルは左上のトグルで開閉でき、幅は展開 180 / 収納 40（収納時はアイコンのみ）です。 開閉状態は設定へ保存し、次回起動時に復元します。

ページの内容は**選択時に 1 度だけ生成**し、以降は同じ表示を使い回します（一覧のスクロール位置や生成済みのサムネイルを保つため）。

### 3.1 キャプチャ ページ

3 行（ツールバー / プレビュー / ステータスバー）で構成します。

| 位置 | 内容 |
| --- | --- |
| ツールバー | ☰（メニュー）/ ファイル名テンプレート（入力欄）/ 保存 / スクリーン選択 / ウィンドウ選択 / 範囲選択 / 切り出し / 自動切り出し |
| プレビュー | 画像の表示（ドラッグでパン、`Ctrl` + ホイールでズーム、ホイールでパン）。 切り出し中は選択オーバーレイとルーペを重ねる |
| ステータスバー左 | ポインタ座標（画像ピクセル）/ 画像サイズ / 保存済み・未 / 保存ファイル名 / 通知メッセージ |
| ステータスバー右 | 縮小 / 拡大率スライダ（10〜500%）/ 拡大 / Fit / 拡大率 |

ツールバーのファイル名テンプレートは編集するとその場で設定へ保存します（設定ページには置きません）。

☰ メニューの構成:

| 項目 | ショートカット（表示のみ） |
| --- | --- |
| 画像を保存 | `Ctrl+S` |
| コピー | `Ctrl+C` |
| 貼り付け | `Ctrl+V` |
| 元に戻す | `Ctrl+Z` |
| 元に戻すを取り消す | `Ctrl+Y` |
| 撮影 - スクリーン選択 / ウィンドウ選択 / 範囲選択 | — |
| 切り出し | `Ctrl+R` |
| Crop - 自動切り出し | — |
| ファイル名テンプレートを編集 | — |

### 3.2 キャプチャ選択の操作

| 種別 | 操作 |
| --- | --- |
| スクリーン選択 | カーソル下のモニターをハイライトし、**左クリック**または **Enter** で確定する |
| ウィンドウ選択 | カーソル下のウィンドウをハイライトし、**左クリック**または **Enter** で確定する |
| 範囲選択 | ドラッグで矩形を指定し、**Enter** で確定する（矢印キーで微調整できる） |

- 確定した領域を切り出し、プレビューへ設定します（撮影前の画像は編集履歴へ退避します）。
- **Escape** または他ウィンドウへの切り替えでキャンセルします（プレビュー・履歴・ステータスとも変更しません）。
- 要素を検出できない位置をクリックしても確定しません（キャンセルは Escape）。
- 対象は**全モニター（仮想スクリーン）**です。 1 モニターに限定しないため、カーソルのあるモニター以外の領域も選べます。
- 設定 `HideMainWindowOnCapture` が true のとき、メイン ウィンドウを**画面外へ退避**してからオーバーレイを表示します（自ウィンドウの写り込み防止）。
- 撮影中はタスクバー・Alt+Tab の一覧に表示しません。
- 範囲選択の切り出しは**閉区間**（始点・終点の画素を含む）です。

### 3.3 選択中のラベル

撮影・切り出しのオーバーレイは、選択矩形の左上へ行を縦に積んだラベルを表示します。

| 行 | 内容 | 設定（外観設定） |
| --- | --- | --- |
| 1 行目 | サイズラベル（座標・幅×高・表示倍率） | 表示可否 / 文字サイズ / 文字色 / 背景色 |
| 2 行目 | 操作ラベル（確定・キャンセルの方法） | 表示可否 / 文字サイズ / 文字色 / 背景色 |
| 3 行目 | 情報ラベル（ウィンドウ選択時のウィンドウ タイトル） | 表示可否 / 文字サイズ / 文字色 / 背景色 |

座標は画像ピクセルで表示します。

### 3.4 ホットキー

| 設定 | 既定値 |
| --- | --- |
| `SelectScreenHotKey`（全画面キャプチャ） | `Ctrl + Shift + Q` |
| `WindowSelectHotKey`（ウィンドウ選択キャプチャ） | `Ctrl + Shift + W` |
| `AreaSelectHotKey`（範囲選択キャプチャ） | `Ctrl + Shift + E` |

- 書式は `Ctrl + Shift + Q`（大文字小文字は区別しません。 `Ctrl+Shift+Q` も受理します）。
- **修飾キーが最低 1 つ必要**です。 解釈できない文字列は入力欄が赤くなり、設定は変わりません。
- 「クリア」で未設定にできます（未設定のホットキーは登録しません）。
- 登録は起動時と設定変更時に行います。 他のアプリと競合して登録できなかった組み合わせは、アプリを止めずにログへ記録します。

### 3.5 フォルダビュー ページ

保存先フォルダ（設定の `SaveFolderPath`。 既定は `{MyPictures}\SaveEvidence`）の画像をサムネイルで一覧します。

| 位置 | 内容 |
| --- | --- |
| ツールバー | 最新の情報に更新 / 特大・大・中 / 昇順・降順 |
| 一覧 | サムネイル（画像の縦横比のまま表示。 下端にファイル名） |
| ステータスバー右 | 一覧しているフォルダのパス |

- 対象は `.png` / `.jpg` / `.jpeg` / `.bmp` / `.gif` / `.tiff` / `.tif` / `.webp` です（大文字・小文字は区別しません）。
- 表示モードと並べ替えの向きは設定へ保存し、次回起動時に復元します。
- サムネイルは背景で生成し、できた 1 件から順に表示します（一覧の表示を生成の時間で待たせません）。 ページを表示していない間は低負荷（1 件ずつ）で生成します。
- 項目へカーソルを重ねると背景が薄い灰色になり、枠が青くなります。
- ダブルクリックで OS の既定アプリで開きます。

### 3.6 Undo 一覧ページ

編集履歴をサムネイルで一覧します。 並び順は**やり直し（現在に近い未来から）→ 現在 → 取り消し（現在の直前から過去へ）**で、現在の画像は青い太枠で示します。

| 位置 | 内容 |
| --- | --- |
| ツールバー | 特大・大・中 |
| 一覧 | 履歴のサムネイル（ラベルは `Redo N` / `現在` / `Undo N`） |
| ステータスバー右 | 「ダブルクリックで外部ツール表示」 |

- 表示モードは設定へ保存し、次回起動時に復元します。
- ダブルクリックすると、その履歴の画像を**元の寸法のまま**一時ファイル（PNG）へ書き出し、OS の既定アプリで開きます。 一時ファイルは OS の一時領域に残します（既定アプリが読み終える時刻を確定できないため）。

### 3.7 設定ページ

7 セクションを縦 1 列で表示します（変更はその場で設定ファイルへ保存します）。

| セクション | 内容 |
| --- | --- |
| 外観テーマ設定 | テーマ（ライト / ダーク / システム） |
| 保存設定 | 保存先フォルダ（参照ボタン付き。 解決できない場合は入力欄の背景が変わり、ツールヒントで理由を示す） |
| 画像設定 | 画像を中央に配置（オフの場合は左上に配置） |
| キャプチャ設定 | キャプチャ時にメイン ウィンドウを隠す |
| 矩形選択範囲の制限 | 画像外の選択を禁止（境界内にクリップ） |
| ホットキー設定 | 全画面 / ウィンドウ選択 / 範囲選択（各「クリア」付き） |
| 外観設定 | 下記の 8 カテゴリ。 見出しの右端に「デフォルト値に戻す」 |

「外観設定」のカテゴリ（この順序）:

| カテゴリ | 項目 |
| --- | --- |
| ラベル設定 | 選択矩形のサイズを表示 / 矩形操作を矩形内に表示 / 選択中のウィンドウのタイトルを表示 / カーソル位置の座標をカーソル横に表示 / ルーペの中心座標をルーペ上部に表示 |
| 選択枠・暗転 | 選択枠の色 / 選択枠の太さ / 選択矩形の最小サイズ / 暗転オーバーレイの色 |
| ドラッグハンドル・マーカー | ハンドルの色 / サイズ / 判定半径 / マーカーの色 / 長さ |
| ルーペ | 枠色 / 枠の太さ / 十字線の色 / 選択矩形の破線の色 A / 色 B / 拡大率 / サイズ / カーソルからのオフセット |
| ルーペの画像外の色 | 画像外の色 |
| 選択矩形内のラベル | 1〜3 行目のテキスト色 / 背景色 / フォント サイズ |
| カーソル位置の座標ラベル | テキスト色 / 背景色 / フォント サイズ |
| ルーペの中心座標ラベル | テキスト色 / 背景色 / フォント サイズ |

色は OS の色ダイアログで選び、設定へは `#AARRGGBB` の文字列として保存します。

## 4. プレビューの切り出し

ツールバーの「切り出し」ボタン（または `Ctrl+R`）は、**押すたびに「開始 → 確定 → キャンセル」を切り替え**ます（どの操作を行うかはコアが判断します）。

| 状態 | 動作 |
| --- | --- |
| 未開始 | プレビューの上へ選択オーバーレイとルーペを重ねる |
| 選択済み | 現在の選択矩形で切り出し、編集履歴へ退避する |
| 選択なし | キャンセルする（画像を変えない） |

- 切り出しは**閉区間**（始点・終点の画素を含む）です。
- 切り出し中はカーソル位置を拡大する**ルーペ**を表示し、選択矩形の破線をルーペ画像へ重ねます。
- 切り出しの対象は**表示中の画像**です（画像を別に指定しません）。

「自動切り出し」はプレビュー画像からウィンドウ枠を検出し、切り出し範囲を提示します。

| 操作 | 動作 |
| --- | --- |
| 実行 | 検出した矩形を水色の実線枠（2 DIP）で表示する |
| カーソル移動 | カーソルを含む矩形のうち面積が最小のものを赤枠 + 半透明の赤塗りで強調する |
| 矩形内のダブルクリック | その矩形で切り出す（編集履歴へ退避する） |
| 矩形外のダブルクリック / Escape | キャンセルする（画像を変えない） |
| 再実行（モード中のボタン） | キャンセルする |

検出できなかった場合はステータスバーへ通知します。 自動切り出し中もホイールでのズーム・パンができます。

### 4.1 編集履歴（戻す / やり直し）

☰ メニューの「元に戻す」（`Ctrl+Z`）/「元に戻すを取り消す」（`Ctrl+Y`）で履歴を移動します。 撮影と切り出しの直前に現在の画像を履歴へ退避するため、撮影前・切り出し前へ戻せます。 履歴は最大 5 段です。

## 5. 操作ログ

出力先は `%LOCALAPPDATA%\SaveEvidence\logs\SaveEvidence.log`（日次ローテーション・7 日保持。 Serilog）です。 他の UI 版と同じファイルへ出力するため、比較できます。

| 内容 | 例 |
| --- | --- |
| 起動 / 終了 | `[App.WinForms] アプリケーション起動 (version=0.1.0.0)` |
| 一覧の読み込み失敗 | `[App.WinForms] 一覧の読み込みで例外が発生: C:\images` |
| サムネイルの生成失敗 | `[App.WinForms] サムネイルの生成で例外が発生` |
| サムネイルの先読み | `[App.WinForms] サムネイルの先読みを開始: FolderView 対象=3 件` |
| ホットキーの登録失敗 | `[App.WinForms] ホットキーの登録に失敗: ScreenSelect (Ctrl + Shift + Q)` |
| 外部ツールでの表示失敗 | `[App.WinForms] ファイルを外部ツールで表示できません: C:\images\a.png` |
| 未処理の例外 | `[App.WinForms] 未処理の例外: Application.ThreadException` |

撮影セッション・切り出しセッション・ズーム・選択操作のログは撮影スタック（接頭辞 `[CapturePreview]`）が出力します（アプリ側で同じ操作を二重に記録しません）。

未処理の例外は、アプリ全体（`AppDomain`）/ UI スレッド（`Application.ThreadException`）/ 待機されなかったタスク（`TaskScheduler`）の 3 経路を記録します。 UI スレッドの例外は記録後に処理を継続し、ウィンドウの表示を維持します。

## 6. 画像の保存仕様

- ファイル名は**ファイル名テンプレート**から生成します。 既定値は `screenshot_007_{date}-{time}.png` です。
- 記法は `{date}`（`yyyyMMdd`）/ `{time}`（`HHmmss`）/ `{yyyy}` `{MM}` `{dd}` `{HH}` `{mm}` `{ss}` / `{{` `}}`（リテラルの波括弧）です。
- ファイル形式は**拡張子で決まります**（既定は PNG）。
- 同名のファイルが既にある場合は**上書きを確認**します（「はい」で上書き、「いいえ」・Escape・ダイアログを閉じる場合は保存しません）。
- 保存後はファイル名の右端の数値を +1 してテンプレートを更新します。
- 保存先フォルダが存在しない場合、保存は行わずステータスバーへ通知します。

## 7. 設定ファイル

保存先は `%LOCALAPPDATA%\SaveEvidence\settings.json` です（他の UI 版と共有します）。

| 項目（抜粋） | 内容 |
| --- | --- |
| `MainWindowBounds` / `MainWindowState` | メイン ウィンドウの位置・サイズ（画面物理ピクセル）とウィンドウ状態 |
| `IsNavigationExpanded` | ナビゲーション パネルの展開状態 |
| `ThemeMode` | `Light` / `Dark` / `System` |
| `SelectScreenHotKey` / `WindowSelectHotKey` / `AreaSelectHotKey` | グローバル ホットキー |
| `FileNameTemplate` / `SaveFolderPath` | ファイル名テンプレート / 保存先フォルダ |
| `CenterAlign` | 画像を中央に配置するか（オフは左上） |
| `HideMainWindowOnCapture` | 撮影時にメイン ウィンドウを隠すか |
| `ClampToSourceBounds` | 画像外の選択を禁止するか |
| `FolderExtraLargeIconSize` / `FolderLargeIconSize` / `FolderMediumIconSize` | フォルダビューの表示モードごとのサムネイルの大きさ |
| `FolderViewModeIndex` / `FolderViewSortAscending` | フォルダビューの表示モードと並べ替えの向き |
| `UndoViewModeIndex` | Undo 一覧の表示モード |
| 外観設定（色・寸法） | 選択枠・暗転・ハンドル・マーカー・ルーペ・ラベル・座標ラベル |

- 色は `#AARRGGBB`（8 桁）または `#RRGGBB`（6 桁・アルファは 255）で保存します。
- 書式はインデント付き・コメント可・末尾カンマ可です。
- 読み込みに失敗した場合は既定値で起動します（設定ファイルの破損で起動できなくならないようにするため）。
- **書き込みは前回保存した内容と同一の JSON の場合は行いません**（無駄な書き込みを避けるため）。

### 7.1 ウィンドウ配置の保存・復元

- 保存は終了時（ウィンドウを閉じる直前）に行います。 最大化・最小化中でも**通常表示の矩形**を保存します。
- 復元は起動時に、保存した位置・サイズ・状態をそのまま適用します。 **幅・高さが 1 未満の壊れた値は既定サイズ（1200 × 800）へフォールバック**します。
- 保存に失敗しても終了は妨げません（ログへ Warning を記録します）。

## 8. 公開 API

本アプリは**実行可能ファイル**であり、他のプロジェクトから参照する公開 API を持ちません。 再利用する層（`App.Core` / `Parts.CapturePreview.*` / `Platform.WinForms`）が公開 API を提供し、本アプリはその利用者です。 各層の API はそれぞれの `docs/SPEC_API.md` を参照してください。

## 9. エラー時の挙動

| 状況 | 挙動 |
| --- | --- |
| 画面キャプチャを取得できない | 撮影を中止し、画像・履歴・ステータスを変えない（原因は撮影スタックがログへ記録する） |
| 設定の値が範囲外 | 撮影セッションへの反映で例外になった場合も UI を壊さず、ログへ記録する |
| 保存先フォルダが無効 | 保存せず、ステータスバーへ「保存できませんでした」と表示する |
| ホットキーを登録できない | Warning を記録し、アプリは継続する（そのホットキーが使えないだけ） |
| フォルダの読み込みに失敗 | 一覧を空にし、Error を記録する |
| 画像ファイルを開けない | Error を記録し、操作は妨げない |
| UI スレッドで未処理の例外 | Critical を記録し、ウィンドウの表示を維持する |
| 設定ファイルを読み書きできない | 既定値（または現状）のまま続行する |

## 10. 制限事項

| 制限 | 内容 |
| --- | --- |
| プラットフォーム | Windows のみです（GDI+ と Win32 の画面キャプチャを使うため）。 |
| 描画の補間 | プレビューの拡大・縮小は最近傍です（画素を等倍のまま敷くため）。 ファイルのサムネイルは GDI+ の高品質バイキュービックで縮小し、編集履歴のサムネイルはコアの面積平均で縮小します。 |
| サムネイルの画質 | ファイルのサムネイルはコアの面積平均と画素が一致しません（表示専用であり、保存画像は元の画素のまま変わりません）。 |
| 横ホイール | WinForms の `MouseEventArgs` から横方向の回転量を取得できないため、常に縦方向として扱います。 |
| ウィンドウの見た目 | タイトルバーとウィンドウ操作ボタンは OS 標準です（独自のタイトルバーを描きません）。 タスクバーのアイコンはシステム既定です。 |
| アイコン | ツールバーとナビゲーションのアイコンは GDI+ の図形で描きます（SVG やアイコン フォントを使いません）。 |
| 一覧の見た目 | サムネイルに影を付けません（枠線とホバーの帯で示します）。 |
| 色の入力 | 色は OS の色ダイアログで選びます（アプリ内のカラー ピッカーを持ちません）。 ダイアログは不透明度を扱えないため、選んだ RGB に**現在の不透明度**を付け直します（半透明の設定が不透明になりません）。 |
| 一時ファイル | 履歴の外部表示で書き出した一時ファイルは削除しません（既定アプリが読み終える時刻を確定できないため）。 |
