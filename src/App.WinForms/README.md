# App.WinForms

## 1. 概要

SaveEvidence の **WinForms 版アプリ**です。 画面キャプチャ（全画面 / ウィンドウ / 範囲）、取り込んだ画像の切り出し（手動 / 自動）、保存・クリップボード連携・編集履歴・保存先フォルダのサムネイル一覧を提供します。

UI 非依存のコア（`App.Core`）と撮影スタック（`Parts.CapturePreview`）を共有し、**UI 層だけを WinForms（GDI+）で実装**しています。 設定ファイルとログは他の UI 版と同じ場所を共有するため、起動した実行ファイルが違っても同じ設定・同じログで追跡できます。 タスク バーでも 1 つのアプリとしてまとまります（4 UI 版が同じ `AppUserModelId` を設定します）。

| 項目 | 内容 |
| --- | --- |
| 実行ファイル | `SaveEvidence.WinForms.exe` |
| 設定ファイル | `%LOCALAPPDATA%\SaveEvidence\settings.json` |
| ログ | `%LOCALAPPDATA%\SaveEvidence\logs\SaveEvidence.log`（日次ローテーション・7 日保持） |
| 描画 | GDI+（`System.Drawing`）。 画像の縮小は `EsUtil.Platform.Core` の面積平均を使う |
| アイコン | 他の UI 版と同じ SVG ファイル（`App.Core/src/Icons/*.svg`。 `SvgIconLoader` が単一所有する）を共有し、GDI+ のパスへ変換して描く |

## 2. システム要件

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 以降（Win32 の画面キャプチャ・要素検出・ウィンドウ操作を使う） |
| ランタイム | .NET 10（デスクトップ ランタイム） |
| DPI | モニター単位（Per-Monitor V2）。 起動時に有効化します |

## 3. ビルド

```powershell
dotnet build src/App.WinForms/src/App.WinForms.csproj -c Release
```

ソリューション全体をビルドする場合は `SaveEvidence.slnx` を指定します。

```powershell
dotnet build SaveEvidence.slnx -c Release
```

## 4. 実行

```powershell
src/App.WinForms/src/bin/Release/net10.0-windows/SaveEvidence.WinForms.exe
```

起動すると左にナビゲーション パネル（キャプチャ / フォルダビュー / Undo 一覧 / 設定）、右にページ内容が表示されます。 起動直後はプレースホルダ画像がプレビューに入っており、保存・コピー・切り出しの操作をすぐに試せます。

## 5. 使い方

### 5.1 キャプチャ ページ

| 操作 | 動作 |
| --- | --- |
| スクリーン選択（アイコン） | カーソル下のモニターをハイライトし、クリックまたは Enter で確定 |
| ウィンドウ選択（アイコン） | カーソル下のウィンドウをハイライトし、クリックまたは Enter で確定 |
| 範囲選択（アイコン） | ドラッグで矩形を指定し、Enter で確定（矢印キーで微調整できる） |
| 保存（アイコン / `Ctrl+S`） | ファイル名テンプレートから名前を生成して保存（同名時は確認） |
| 切り出し（アイコン / `Ctrl+R`） | 押すたびに「開始 → 確定 → キャンセル」を切り替える |
| ☰ メニュー | 保存 / コピー（`Ctrl+C`）/ 貼り付け（`Ctrl+V`）/ 元に戻す（`Ctrl+Z`）/ 元に戻すを取り消す（`Ctrl+Y`）/ 撮影 3 種 / 切り出し / 自動切り出し / ファイル名テンプレートの編集 |

- ツールバーの構成は他の UI 版と同じです（☰ / ファイル名テンプレート / 保存 / 撮影 3 種 / 切り出し）。 自動切り出しは ☰ メニューから実行します。
- ナビゲーション パネルは左上のトグルで開閉できます（開閉状態は設定へ保存し、次回起動時に復元します）。
- 撮影の対象は**全モニター（仮想スクリーン）**です。 撮影中はメイン ウィンドウを画面外へ退避し、キャプチャ除外を設定します（設定で無効にできます）。
- 切り出しと範囲選択の矩形は**閉区間**（始点・終点の画素を含む）です。
- 終了は Escape です（プレビュー・履歴・ステータスとも変更しません）。
- 切り出し中はカーソル位置を拡大する**ルーペ**が表示されます（サイズ・拡大率・色は設定に追従）。

### 5.2 ツールバーとステータスバー

- ツールバーは横幅に収まらない場合に折り返します（ファイル名テンプレートが長い場合もアイコンが隠れません）。
- ステータスバー左は「ポインタ座標 / 画像サイズ / 保存済み・未 / 保存ファイル名 / 通知メッセージ」、右は「縮小 / 拡大率スライダ（10〜500%）/ 拡大 / Fit / 拡大率」です。
- マウス ホイールはパン（`Shift` 併用で横）、`Ctrl` 併用でカーソル位置を中心としたズームになります。

### 5.3 フォルダビュー ページ

保存先フォルダの画像をサムネイルで一覧します。

| 操作 | 動作 |
| --- | --- |
| 最新の情報に更新 | フォルダを読み直す |
| 特大 / 大 / 中 | 表示モード（サムネイルの大きさ）を切り替える |
| 昇順 / 降順 | ファイル名で並べ替える |
| ダブルクリック | OS の既定アプリで開く |

### 5.4 Undo 一覧ページ

編集履歴（やり直し → 現在 → 取り消し）をサムネイルで一覧します。 現在の画像は青い太枠で示します。 ダブルクリックすると**元の寸法のまま**一時ファイルへ書き出し、OS の既定アプリで開きます。

### 5.5 設定ページ

6 セクション（保存設定 / 画像設定 / キャプチャ設定 / 矩形選択範囲の制限 / ホットキー設定 / 外観設定）を縦 1 列で表示します。 変更はその場で設定ファイルへ保存されます。 本 UI 版は**ダークテーマを使用しない**（常に明色。 設定ファイルの `ThemeMode` は読みますが反映せず、テーマの選択も表示しません）。

- **ホットキー設定**: `Ctrl + Shift + Q` の形式で入力します（大文字小文字は区別しません。 修飾キーが最低 1 つ必要です）。 「クリア」で未設定に戻せます。
- **外観設定**: 選択枠・暗転・ドラッグハンドル・マーカー・ルーペ・ラベル・座標ラベルの色と寸法を指定します。 色の選択は OS の色ダイアログで行います。 「デフォルト値に戻す」で既定値へ戻せます。

### 5.6 グローバル ホットキー

設定に保存したホットキーを起動時に登録し、他のアプリが前面にあってもキャプチャを開始できます。 他のアプリと競合して登録できなかった組み合わせは、ログへ Warning として記録し、アプリは継続します（設定ページで組み合わせを変えるか、クリアしてください）。

## 6. テスト

```powershell
dotnet test src/App.WinForms/tests/App.WinForms.Tests.csproj
```

UI スレッドとウィンドウ（ハンドル）を必要としない範囲を検証します。 色文字列の解析、サムネイルの縮小とキャッシュ、GDI+ とコアの画像の相互変換、SVG のパス データの解析、アイコンの描画、ログの書式、撮影設定への写像を確認します（このうち写像は `App.Core` の単一所有であり、`App.Core.Tests` に同等のテストが無いため**利用側の責任**で本プロジェクトが固定しています）。

サムネイル生成のスケジューラ（優先度・並列度・中断）と表示モードの表示名・拡張子判定・生成の優先度は `App.Core.Tests` が検証します。

## 7. プロジェクト構成

```text
App.WinForms/
├── README.md                # 本ファイル
├── docs/                    # SPEC_ExtFunc.md（外部機能仕様書）/ SPEC_System.md（システム仕様書）
└── src/
    ├── App.WinForms.csproj  # WinExe / net10.0-windows10.0.17763.0 / UseWindowsForms
    ├── Program.cs           # DPI 対応 → コアの組み立て（AppServices） → ウィンドウ表示
    ├── AppServices.cs       # 共有するコアオブジェクトの束（ViewModel / 設定 / 履歴 / 一覧の状態）
    ├── Icons/
    │   ├── AppIcon.cs            # 表示するアイコンの種類
    │   ├── IconLoader.cs         # 共有 SVG の読み込みと GDI+ のビットマップへの描画
    │   └── SvgPathData.cs        # SVG のパス データ（d 属性）→ GDI+ のパス
    ├── Logging/
    │   └── AppLog.cs             # ログ定義（接頭辞 [App.WinForms]・Serilog のファイル出力）
    ├── Services/
    │   ├── CaptureFlow.cs            # キャプチャの開始（多重起動の防止）
    │   ├── ClipboardImageService.cs  # クリップボードとの画像の受け渡し
    │   ├── EditHistory.cs            # 編集履歴（戻す / やり直し）の実行
    │   ├── GdiBitmapInterop.cs       # GDI+ のビットマップ ⇔ コアの画像
    │   ├── SettingsColorMath.cs      # 設定の色文字列 ⇔ 色
    │   └── SettingsJsonContext.cs    # 設定の JSON ソース生成（トリミング / Native AOT 対応）
    └── Views/
        ├── MainForm.cs           # ナビゲーション・配置の復元と保存・ホットキー
        ├── AppStyles.cs          # 共通の配色とフォント（明色固定）
        ├── UiFactory.cs          # 共通のコントロール生成（配色・余白・ツールヒント）
        ├── ToolButton.cs         # アイコン付きツールバー ボタン
        ├── PageContent.cs        # ページの内容と表示切り替えの処理の束
        ├── CapturePage.cs        # キャプチャ ページ（撮影 / 切り出し / ズーム / ルーペ / 履歴）
        ├── FolderViewPage.cs     # フォルダビュー ページ（サムネイル一覧・表示モード・並べ替え）
        ├── UndoPage.cs           # Undo 一覧ページ（履歴のサムネイル一覧・外部表示）
        ├── SettingsPage.cs       # 設定ページ（保存 / ホットキー / 外観）
        └── ThumbnailGeneration.cs # サムネイルの縮小と項目への反映
```

画像の保存（`IImageWriter`）は `App.Core` の実装（全 UI 共通）を使います。 表示モードの表示名・一覧に含める画像の拡張子の判定・設定 → 撮影設定の写像・件数上限付きキャッシュ・サムネイル生成のスケジューラと優先度も `App.Core` の `internal` 型をそのまま使います（`InternalsVisibleTo` を通じて参照するため、同じ表を二重に持ちません）。

## 8. 機能一覧

| 機能 | 内容 |
| --- | --- |
| 撮影 | スクリーン選択 / ウィンドウ選択 / 範囲選択（全モニターが対象） |
| 切り出し | 手動（切り出しボタン・`Ctrl+R`）と自動（ウィンドウ枠の検出） |
| ズーム | 10〜500%（スライダ・⊖ / ⊕・Fit・`Ctrl` + ホイール・ホイールでパン） |
| ルーペ | 切り出し中にカーソル位置を拡大表示（設定に追従） |
| 保存 | ファイル名テンプレートから生成（同名時は上書き確認） |
| クリップボード | 画像のコピー（`Ctrl+C`）と貼り付け（`Ctrl+V`） |
| 編集履歴 | 最大 5 段の取り消し / やり直し（Undo 一覧ページで一覧） |
| 一覧 | 保存先フォルダのサムネイル一覧（表示モード 3 種・並べ替え） |
| 設定 | 保存先・ホットキー・撮影の外観（色と寸法） |
| グローバル ホットキー | 3 種のキャプチャを他のアプリが前面でも開始できる |
| ログ | 起動 / 終了 / 撮影・切り出し・ズーム・選択の操作（共有のログファイル） |

## 9. 配布形態

配布物は **Single（単一 exe・自己完結）**（[`buildScript/publish_WinForms.bat`](../../buildScript/publish_WinForms.bat)）です。 exe 1 個で配置でき、
ネイティブ ライブラリは起動時に一時領域へ展開されます。

- **Native AOT は使えません**。 SDK がトリミングを拒否します（`NETSDK1175`「Windows フォームに関して、トリミングの有効化は
  サポートおよび推奨されていません」）。 Native AOT はトリミングを前提とするため WinForms では成立しません。
- 方式は `buildScript/publish_ui.bat` が **Single AOT → Single → EXE** の優先順に選びます（他の UI と同じ規則）。
- 期待する出力先と exe 名は [`.github/release-config.json`](../../.github/release-config.json) が単一所有します。
- 設定の読み書きには JSON ソース生成（`SettingsJsonContext`）を使うため、トリミング / AOT でも設定項目が失われません。
