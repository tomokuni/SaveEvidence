## 1. 概要

`src/LineDetection/sample/` にある **Windows のウィンドウ枠となる辺（線分）の検出サンプルアプリケーション**です。

- クリップボードから貼り付けた画像（スクリーンショット等）の中から、ウィンドウ枠となる **水平・垂直の辺** を検出します。
- 検出した辺を **垂直 / 水平のグループ** に分けて左ペインに一覧表示します。
- 右側には画像を表示し、検出した辺を **水色の線分** として重ね描きします。
- **画像上の線分をホバー** すると赤く強調表示され、一覧の対応する行も同時に強調表示されます。
- **一覧の行をホバー** すると、画像上の対応する線分が赤く強調表示され、一覧の行も強調表示されます。
- **線分または一覧の要素をクリック** すると、線分と要素がオレンジ色で強調表示されます（もう一度クリックで解除）。
- **マウス位置をルーペ（LoupeControl）で拡大表示** します。ホバー中の線分はルーペ内に **赤い破線**、選択中の線分は **オレンジの破線** で表示されます。
- 検出方式は **ロジック（画像処理）方式** です。

## 2. 実行方法

```powershell
dotnet run --project src/LineDetection/sample/LineDetection.Sample.csproj
```

リリース構成で実行する場合:

```powershell
dotnet run -c Release --project src/LineDetection/sample/LineDetection.Sample.csproj
```

または `RunSample.bat` をダブルクリックすると、リリースビルド後にアプリが起動します。

> 本サンプルは独立したプロジェクトです（LineDetection ライブラリ + LoupeControl ライブラリ + OpenCvSharp5 を使用）。

## 3. 操作方法

左ペイン上部の**操作モード**（ラジオボタン）で 3 つの動作を切り替えます。

| 操作モード | 表示内容 |
| --- | --- |
| ① 線分検出 | 検出方式・検出結果・選択中。Ctrl+V で貼り付けた画像を検出 |
| ② dataset画像を使用 | dataset画像ドロップダウン・検出方式・検出結果・選択中。選択した画像を検出し、JSON と照合 |
| ③ dataset画像の全検証 | 検出方式・検証レポート。選択時に dataset の全画像を自動で一括照合 |

| 操作 | 内容 |
| --- | --- |
| 検出方式 ComboBox | すべてのモードで表示。検出方式（ロジック）。切替時に既存の画像で自動再検出 |
| 操作モード（ドロップダウン） | ①検出 / ②dataset単一 / ③dataset全検証 を切り替え。③を選択すると全画像を自動検証 |
| クリップボードから貼り付け（Ctrl+V） | クリップボードの画像（スクリーンショット等）を貼り付けて選択中の方式で検出。Avalonia のクリップボード API → Win32 の CF_DIB の順で取得 |
| dataset画像 ComboBox（②） | `dataset` 内の画像を選択すると、その画像を表示して検出し、`GroundTruthWindows[0].Bounds`（ドメイン座標・排他座標）と **0px 誤差** で照合。一致・不一致を左ペインに表示 |
| ③の自動検証 | ③「dataset画像の全検証」を選択すると、出力ディレクトリの `dataset` 内の全画像について、検出結果から復元した矩形と `GroundTruthWindows[0].Bounds` を **0px 誤差** で照合。結果サマリと検証レポートを左ペインに表示（手動ボタンなし） |
| 垂直の辺（N）一覧 | ①/②で左ペインに表示。検出した垂直の辺を一覧表示（長い辺を上に表示）。行をホバーすると画像の線分が赤く強調、クリックでオレンジ強調（再クリックで解除） |
| 水平の辺（N）一覧 | ①/②で左ペインに表示。検出した水平の辺を一覧表示（長い辺を上に表示）。行をホバーすると画像の線分が赤く強調、クリックでオレンジ強調（再クリックで解除） |
| 画像上をマウス移動 | 線分の近くにポインタを置くと、その線分が赤く強調表示され一覧の行も強調。同時にマウス位置がルーペで拡大表示される（ホバー中の線分はルーペ内に赤い破線で表示） |
| 画像上をクリック | クリック位置の線分を選択トグル（オレンジ強調。再クリックで解除） |
| 画像上からマウスが出る | ルーペを非表示にする |

## 4. 検出方式

### 方式1: ロジック（Canny + Hough）

- モデル不要の画像処理方式です。
- Canny エッジ検出 → HoughLinesP で線分を抽出し、角度で水平 / 垂直に分類します。
- 同一直線上に並ぶ線分をクラスタリングして長い辺へ統合し、最小長・エッジ支持率でフィルタします。
- 近接する平行線（透過枠で分裂した枠線等）は 1 本に統合し、枠線を元画像の輝度プロファイルの**外側の境界（排他座標）**へ補正します。
- 線分が矩形（ウィンドウの 4 辺）を構成できる場合は、対辺同長・コーナー近接を満たし、
  画像の端に最も近い矩形の 4 辺を優先出力します（ウィンドウ枠の検出を目的とするため）。
- 矩形を構成できない場合は、ウィンドウ枠だけでなく画像内の長い水平・垂直のエッジも検出されます。
