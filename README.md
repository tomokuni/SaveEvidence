## 1. 概要

SaveEvidence は Windows デスクトップ上の画面をキャプチャし、プレビュー・編集・保存するためのアプリケーションです。  
スクリーン全体、特定ウィンドウ、任意の矩形領域の 3 種類のキャプチャ方法をサポートし、グローバルホットキーから瞬時に起動できます。

キャプチャした画像はアプリ内でプレビュー表示され、切り出し（クロップ）、クリップボード連携、ファイル保存などの操作が可能です。

## 2. 機能一覧

### 2.1 画面キャプチャ

| キャプチャ方法 | 説明 | 既定のホットキー |
| --- | --- | --- |
| **スクリーン選択** | マルチスクリーン環境でキャプチャする画面をクリックして選択します。シングルスクリーン時は即時キャプチャされます。 | `Ctrl + Shift + Q` |
| **ウィンドウ選択** | マウスカーソル下のウィンドウを自動検出し、クリックで選択してキャプチャします。 | `Ctrl + Shift + W` |
| **範囲選択** | マウスドラッグで自由に矩形領域を指定してキャプチャします。 | `Ctrl + Shift + E` |

キャプチャ中はメインウィンドウが自動的に非表示になり、操作の妨げになりません（設定画面で切替可能）。  
キャプチャ中の操作を中断するには `Esc` キーを押します。

### 2.2 画像プレビューと編集

キャプチャした画像はメインウィンドウのプレビューエリアに表示され、以下の編集操作が可能です。

#### 2.2.1 切り出し（クロップ）

- プレビュー画像上でマウスドラッグするだけで切り出しモードが開始されます
- 選択領域は 8 方向ハンドルでリサイズ可能
- 選択領域内をドラッグして移動可能
- アプリ内のボタンまたはコンテキストメニューから「切り出し」を実行

#### 2.2.2 自動ウィンドウ検出切り出し

- 画像内のウィンドウ領域を背景色から自動判定して切り出します
- 画像四隅の背景色（最頻色）を基準に、背景色と異なるピクセルが現れる境界を上・下・左・右から探索してウィンドウ領域を検出する方式

#### 2.2.3 クリップボード連携

| 操作 | ショートカット |
| --- | --- |
| 画像をクリップボードにコピー | `Ctrl + C` |
| クリップボードから画像を貼り付け | `Ctrl + V` |

クリップボードに画像がない場合は貼り付けできません。

#### 2.2.4 アンドゥ / リドゥ

- 最大 5 段階のアンドゥに対応
- 切り出し操作前の状態に戻せます
- アンドゥを取り消すリドゥ（やり直し）にも対応（`Ctrl + Y` / メニュー「Image - 元に戻すを取り消す」）

#### 2.2.5 ズーム

- ズーム率の選択肢（フライアウト）: 自動、10、15、25、35、50、75、100、150、200、250、350、500%
- ⊖⊕ ボタン: 10、12、15、20、25、33、40、50、62、75、80、90、100、110、125、150、200、250、300、350、400、450、500% の 23 段階で拡大／縮小
- `Ctrl + マウスホイール` または `Ctrl + +/-` キーで拡大／縮小（Ctrl+ホイールは現在の拡大率 ×1.1 ／ ÷1.1、10〜500% にクランプ）
- 自動フィットモード（画像をウィンドウに合わせる。Fit 中の拡大率も % 表示）
- ズーム中心はマウスポインタ位置（画像内）。画像外（ビューポートの空き領域）ではビューポート中心を基準に拡大縮小
- パン（画像の移動）: マウスドラッグまたはホイールでスクロール（Shift+ホイールで横スクロール）。拡大時はスクロールバーも表示

#### 2.2.6 ルーペ（拡大鏡）

- キャプチャ選択画面（範囲選択中）でマウス位置を拡大表示
- 表示モードは起動時の初期状態として `LoupeModeValue` で制御（0=非表示 / 1=表示 / 2=自動。0 以外は表示扱い。設定画面に UI はありません）
- 拡大率 4 ～ 32 倍（偶数推奨）
- サイズ 64 ～ 512 ピクセル
- 十字線と外枠の色・太さ、選択矩形破線の色、カーソルからのオフセットをカスタマイズ可能

#### 2.2.7 画像配置

- 設定画面「外観設定」のチェックボックス（スクロール不要時は中央に配置）で切替
- **中央寄せ**: 画像が小さい場合でもパネル中央に表示
- **左上寄せ**: 画像をパネルの左上に配置（スクロール可能）

### 2.3 ファイル保存

#### 2.3.1 ファイル名テンプレート

テキストボックスにテンプレート文字列を入力して保存ファイル名を決定します。

| プレースホルダ | 置換内容 | 例 |
| --- | --- | --- |
| `{date}` | 日付（yyyyMMdd 形式） | `20250101` |
| `{time}` | 時刻（HHmmss 形式） | `120000` |
| `{yyyy}` | 年 4 桁 | `2025` |
| `{MM}` | 月 2 桁 | `01` |
| `{dd}` | 日 2 桁 | `01` |
| `{HH}` | 時 2 桁（24 時間制） | `12` |
| `{mm}` | 分 2 桁 | `34` |
| `{ss}` | 秒 2 桁 | `56` |

プレースホルダは複数組み合わせられます（例: `screenshot_{yyyy}{MM}{dd}_{HH}{mm}{ss}.png`）。

中括弧自体は `{{` / `}}` でエスケープできます（例: `abcd{{e}}f{yyyyMMdd}` → `abcd{e}f20260819`）。

**数値の自動インクリメント**:  
テンプレート内の右端の数値連続が自動的に +1 されます。  
例: `screenshot_01.png` → `screenshot_02.png` → ... → `screenshot_99.png` → `screenshot_100.png`

- 桁数は維持されます（`01` → `02`、`099` → `100`）
- 複数の数値がある場合は一番右の数値の塊がインクリメント対象
- テンプレートは次回起動時に自動復元されます

**バリデーション**:  
ファイル名に使用できない文字（`\ / : * ? " < > |` など）が含まれている場合、テキストボックスの枠が赤く表示され、保存ボタンが無効になります。

**テキストボックスの自動幅調整**:  
テキストボックスの幅は入力内容に応じて自動的に広がります（最小 220px 〜 最大 260px の範囲）。
短いテンプレートは最小幅、長いテンプレートは最大幅に固定され、中間の長さではテキスト全体が収まる幅になります。

#### 2.3.2 保存形式

拡張子によって自動判定されます（既定は PNG）。

| 拡張子 | 形式 |
| --- | --- |
| `.png` | PNG |
| `.jpg` / `.jpeg` | JPEG |
| `.bmp` | BMP |

#### 2.3.3 保存先フォルダ

- 設定画面「保存設定」から保存先フォルダを指定できます
- 既定の保存先: `{MyPictures}\SaveEvidence`（`{MyPictures}` はピクチャフォルダへ展開されます）
- 保存先フォルダが存在しない場合は赤枠でバリデーション表示されます
- 設定は自動保存され、次回起動時に復元されます
- 保存ボタンにマウスを乗せると、現在の保存先フォルダが ToolTip 表示されます

#### 2.3.4 上書き確認

同名ファイルが存在する場合は上書き確認ダイアログが表示されます。

### 2.4 フォルダビューアー

保存先フォルダの画像一覧を表示するページです（左ナビゲーション「フォルダビュー」）。

- **サムネイル一覧表示**: 画像ファイルのサムネイルを表示
- **3 種類の表示モード**: 特大 / 大 / 中
- **行の高さ自動調整**: 各行の高さはその行の最大アイテムの高さに応じて自動調整され、ファイル名の 1 文字目の高さ位置が各行内で揃います
- **ソート機能**: ファイル名の昇順・降順切替
- **表示モード・ソート順の保存**: 選択中の表示モード（特大/大/中）とソート順（昇順/降順）は自動保存され、次回起動時に復元されます
- **ダブルクリック**: 既定のアプリケーションでファイルを開く
- **ステータスバー**: アイテム数・表示モード・ソート状態・フォルダパスを表示

### 2.5 Undo 一覧

左ナビゲーション「Undo 一覧」から、Undo / Redo 履歴と現在のプレビュー画像をサムネイル一覧で表示するページです。

- **表示順**: 時系列順で「新しい → 古い」の固定（Redo → 現在 → Undo）
- **現在の画像の強調**: 現在のキャプチャページに表示中の画像は青枠で強調表示
- **3 種類の表示モード**: 特大 / 大 / 中（選択状態は自動保存・復元）
- **ダブルクリック**: 一時ファイルに保存し、OS の既定アプリケーション（外部ツール）で表示
- **ステータスバー**: アイテム数・表示モードを表示

### 2.6 グローバルホットキー設定

設定画面「ホットキー設定」から各キャプチャタイプのホットキーを変更できます。

- 修飾キー: `Ctrl` / `Alt` / `Shift` / `Win`（複数組合せ可）
- テキストボックスにフォーカスして実際のキーボード入力で設定
- 設定内容はテキストボックスに表示されます
- 設定は自動保存され、次回起動時に復元されます
- ホットキーはメニューの「Capture」系項目の右側にも表示されます（設定と連動）

### 2.7 表示設定

設定画面「外観設定」から以下の項目を変更できます。

| カテゴリ | 設定項目 |
| --- | --- |
| **テーマ** | ライト / ダーク / システム（OS の設定に追従） |
| **画像配置** | 中央寄せ / 左上寄せ（スクロール不要時は中央に配置） |
| **選択枠・暗転** | 選択枠の色・太さ（キャプチャ / 切り出し共通）、選択矩形の最小サイズ、暗転オーバーレイの色 |
| **ドラッグハンドル・マーカー** | ハンドルの色・サイズ・判定半径、マーカーの色・長さ |
| **ルーペ** | 枠色・枠の太さ、十字線色、選択矩形破線の色A/B、拡大率（4 ～ 32 倍）、サイズ（64 ～ 512）、カーソルからのオフセット |
| **市松模様** | プレビュー背景とルーペ背景の色A/B・タイルサイズ |
| **ラベル設定** | キャプチャ選択画面の左上ラベル（サイズ / 操作 / 情報）の表示・文字色・背景色・フォントサイズ、カーソル座標ラベル、ルーペ座標ラベル |
| **フォルダビューアーアイコンサイズ** | 特大 / 大 / 中 |

## 4. インストール方法

### 4.1 ソースからのビルド

```powershell
 git clone https://github.com/your-org/SaveEvidence.git
 cd SaveEvidence
 dotnet publish src/app.AvaloniaUI/src/app.AvaloniaUI.csproj -c Release -r win-x64 -p:PublishAot=true -o Publish
```

`Publish/SaveEvidence.exe` を実行してください（隣のネイティブ DLL も必要です）。

### 4.2 配布物の実行

配布物は `SaveEvidence.exe` とネイティブ DLL のセットです（フォルダーごと配置してください）。

### 5.1 基本操作フロー

```text
1. アプリケーション起動
   └── SaveEvidence.exe を実行
   └── 前回終了時のウィンドウ位置・サイズが復元

2. 画面キャプチャ
   └── ツールバーのボタンまたはグローバルホットキーでキャプチャ開始
   └── キャプチャ中はメインウィンドウが非表示（設定で切替可能）
   └── Esc キーでキャンセル

3. 画像の確認と編集
   └── キャプチャした画像がプレビューエリアに表示
   └── マウスホイール Ctrl+ でズーム調整
   └── 必要に応じて切り出しや自動ウィンドウ検出を実行

4. 画像の保存
   └── ファイル名テンプレートを確認・編集
   └── 「保存」ボタンまたは Ctrl+S で保存
   └── 保存後にファイル名の数値が自動インクリメント
```

### 5.2 画面構成

```text
┌─────────────┬────────────────────────────────────┐
│ ナビパネル   │  タイトルバー（☰ メニュー）          │
│ （左）       ├────────────────────────────────────┤
│ キャプチャ   │  ツールバー                        │
│ フォルダビュー│  [☰] [保存] [キャプチャ3種] [切出]  │
│ Undo 一覧   │  ズーム: [⊖] [スライダ] [⊕] [Fit] [▼ 自動]│
│ 設定        │                                    │
│             ├────────────────────────────────────┤
│             │                                    │
│             │           プレビューエリア           │
│             │                                    │
│             ├────────────────────────────────────┤
│             │  ステータスバー（ポインタ座標 / 画像サイズ / ズーム）│
└─────────────┴────────────────────────────────────┘
```

- 左ナビゲーションでページを切り替えます（キャプチャ / フォルダビュー / Undo 一覧 / 設定）
- 左上の ☰（ハンバーガー）からメニュー（保存 / コピー / 貼り付け / 元に戻す / やり直し / キャプチャ 3 種 / 切り出し / 自動切り出し）を開けます
- ナビパネル上部のトグルボタンでナビパネルを開閉できます（アイコンのみに収納）

## 6. 設定ファイル

設定は以下のパスに JSON 形式で保存されます。

```text
%LOCALAPPDATA%\SaveEvidence\settings.json
```

例:

```json
{
  "SelectScreenHotKey": { "Modifiers": "Control, Shift", "Key": "Q" },
  "WindowSelectHotKey": { "Modifiers": "Control, Shift", "Key": "W" },
  "AreaSelectHotKey": { "Modifiers": "Control, Shift", "Key": "E" },
  "FileNameTemplate": "screenshot_007_{date}-{time}.png",
  "SaveFolderPath": "{MyPictures}\\SaveEvidence",
  "ThemeMode": "System",
  "LoupeZoomLevel": 4,
  "LoupeSize": 160,
  "HideMainWindowOnCapture": true
}
```

保存される設定項目:

- テーマモード（`Light` / `Dark` / `System`。System は OS の設定に追従）
- 各キャプチャタイプのグローバルホットキー
- ファイル名テンプレート文字列
- 保存先フォルダパス（`{MyPictures}` プレースホルダ対応）
- ウィンドウ位置・サイズ・状態・ナビパネル開閉状態
- 外観設定（選択枠・暗転・ハンドル・マーカー・ルーペ・市松模様・ラベル。色は `#AARRGGBB` 形式）
- フォルダビューの表示モード・ソート順、Undo 一覧の表示モード

## 7. アーキテクチャ概要

SaveEvidence は、Avalonia UI 上で CommunityToolkit.Mvvm を使用した MVVM アーキテクチャを採用しています。

```text
┌──────────────────────────────────────────┐
│              View（Window）               │
│  MainWindow                              │
│  CapturePage / FolderViewPage            │
│  UndoPage / SettingsPage                 │
└────────────────┬─────────────────────────┘
                 │ DataBindings & Events
┌────────────────▼─────────────────────────┐
│          ViewModel                        │
│  MainViewModel / FolderViewViewModel     │
│  UndoViewModel                           │
└────────────────┬─────────────────────────┘
                 │
┌────────────────▼─────────────────────────┐
│          Model ＆ Service                 │
│  UndoStack / Settings / SettingsService  │
│  FileNameTemplate / SnipCapture（外部）   │
└──────────────────────────────────────────┘
```

## 8. トラブルシューティング

| 問題 | 原因と対処 |
| --- | --- |
| **ホットキーが反応しない** | 他のアプリケーションが同じホットキーを使用している可能性があります。設定画面から別のキー組合せに変更してください。 |
| **設定ファイルが壊れた** | `%LOCALAPPDATA%\SaveEvidence\settings.json` を削除してアプリを再起動すると、デフォルト設定で再作成されます。 |
